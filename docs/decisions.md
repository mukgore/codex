# 결정 기록

- 2026-10-01: 1차 검증만 수행. 보고서와 원본 폴더 변경 금지. 새로운 설계·입력·서비스·참여자 실험은 사용자 검토 후 진행.
- 사용자가 지정한 mukgore/codex에는 초기 main 커밋이 존재하므로 이력을 보존한 복제본 사용.
- GitHub API로 mukgore 계정 및 저장소 공개 상태 확인. 사용자가 공개 저장소 사용으로 변경 승인. 원자료의 공개 승인은 아니며 개별 데이터·영상·좌표·설문·로컬 절대 경로는 제외.
- data/raw는 최초 해시 검증 복사본. data/inventory.json에 파일별 해시·크기·수정 시각 보관. 수정 시각만으로 실험 버전을 판단하지 않는다.
