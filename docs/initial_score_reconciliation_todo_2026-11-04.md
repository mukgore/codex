# 초기 사람 점수 불일치 재계산 작업 지시서

작성일: 2026-11-04  
상태: 조사 계획과 인수인계. 원자료 재계산 및 불일치 해결은 아직 수행되지 않았다.  
대상: 작품설명서의 초기 사람 평균 0.522, 레벨 3 평균 0.493, 표 10 평균 0.557.

## 목적과 이번 사용자 요청

사용자는 파일 업로드 대신 이 문서를 GitHub에 커밋하고, PC의 Codex CLI가 로컬 자료로 조사를 수행하는 방식을 선택했다. 기존 자료에서 수치의 생성 경로와 불일치 원인을 검증한다. 새로운 참가자 실험, 모델 추론, CAPTCHA 기능 개발로 범위를 넓히지 않는다. 논문과 작품설명서는 근거가 확정되기 전 임의 수정하지 않고, 조사 결과에 따른 수정안을 별도로 제시한다.

## 확인된 수치와 이번 산술 점검

원본의 초기 가중치는 시간 정렬 관절 0.44, 관절 0.31, 위치 경향성 0.25다. 최종 가중치 0.38/0.37/0.25로 대체하지 않는다.

| 대상 | 작품설명서 값 | 표 7 표시 지표로 재구성한 가중합 |
|---|---:|---:|
| 레벨 1 | 0.528 | 0.796×0.44 + 0.564×0.31 + 0.356×0.25 = 0.61408 |
| 레벨 2 | 0.546 | 0.791×0.44 + 0.538×0.31 + 0.453×0.25 = 0.62807 |
| 레벨 3 | 0.493 | 0.747×0.44 + 0.464×0.31 + 0.337×0.25 = 0.55677 |
| 전체 | 0.522 | 본문 레벨별 값의 단순 평균은 0.52233… |

표 10의 0.557은 마지막 행이 아닌 레벨 3 가중합 0.55677의 반올림과 맞는다. 위 재구성값은 반올림된 표의 산술 점검일 뿐 원자료 검증값이 아니다. 0.557만 조사하지 말고 레벨 1·2 및 전체 평균까지 함께 조사한다. 예비 실험 7개 지표 평균 0.402/0.413/0.384와 초기 3개 지표 CAPTCHA 점수를 혼동하지 않는다.

## 실행 순서

### 1 자료와 실험 단위 확인

- 원본은 읽기 전용으로 유지하고 분석 출력은 별도 폴더에 쓴다.
- 파일 해시·사본 관계·입력 파일 목록은 로컬에서만 보존한다.
- 세션/참가자/시행/손/레벨/동작/버전/기준 좌표의 대응표를 만든다.
- 4세션 × 9 trial이 실제 초기 3동작 × 3레벨 자료인지 내용으로 확인한다. 파일 개수만으로 확정하지 않는다.
- 중복은 해시와 내용으로 판정하되 재시도와 단순 복사본을 구분하고, 근거 없이 제외하지 않는다.
- 과거 독립 검증 산출물을 발견하면 입력·코드·산출물의 관계를 확인하고 재사용 가능한 근거를 먼저 읽는다.

### 2 계산식과 생성 경로 추적

- 코드의 최상위 실행부·외부 전송·쓰기 동작을 먼저 읽는다. 과거 스크립트를 그대로 실행해 원본을 덮어쓰지 않도록 계산 함수를 분리하거나 안전한 작업 복사본에서 실행한다.
- 손목 원점 이동, 크기 정규화, XY/XYZ, 각도 단위, 시간 정렬 알고리즘, 검출 실패, 짧은 시행 처리, clipping, 정규화 상수와 상수 산출 범위를 확인한다.
- 예비 Python 코드의 실제 DTW와 최종 브라우저 sliding-window 지표를 같은 것으로 치환하지 않는다.
- 각 파일의 저장 점수/지표와 재계산값을 비교하고 차이의 최초 발생 단계를 찾는다.
- 표 7 지표 평균, 표 10 값, 초기 본문 수치가 어느 입력과 코드에서 생성됐는지 연결한다.

### 3 평균 집계와 원인 검증

- 시행별 초기 점수 → 동작별/레벨별 → 참가자별 → 전체 집계를 재구성한다.
- 참가자 동일 비중, 시행 동일 비중, 프레임 수 가중, 제외/결측 처리의 차이를 명시한다.
- 같은 관측에 같은 고정 가중치와 같은 집계 비중을 적용하면 평균 가중합과 지표 평균의 가중합은 일치해야 한다. 이를 일관성 검사로 사용한다.
- 저장된 코드/설정 근거가 있는 대안만 대조한다. 목표 숫자를 맞추려고 상수·대상을 무차별 탐색하거나 사후 조정하지 않는다.
- 두 경로의 입력/필터/정규화/가중치/집계 중 정확히 무엇이 다른지 확인하고, 해당 차이를 적용·되돌려 결과가 변하는지 검증한다.
- 부동소수점 비교 허용오차와 표시값 반올림 오차를 구분한다. 원자료 검산은 단위에 맞는 명시적 허용오차를 사용한다.

### 4 결과 판정

| 결과 | 보고 방식 |
|---|---|
| 동일 자료·동일 정의에서 한쪽만 재현되고 오류 지점이 특정됨 | 검증된 값, 기존 값, 원인, 영향 범위와 수정안을 제시 |
| 서로 다른 집계/코드/자료에서 각각 재현됨 | 두 경로와 차이를 재현하고 비교 가능성을 설명 |
| 숫자는 재현되지만 실제 생성 경로는 연결되지 않음 | 계산 호환만 확인했다고 보고하고 역사적 출처는 미확정으로 유지 |
| 필요한 원자료/기준 좌표/설정이 부족함 | 검색 범위·부족 파일·복구 가능한 범위와 불가능한 범위를 구체적으로 기록 |

0.557의 표 산술이 맞는다는 이유만으로 실제 사람 평균의 정답으로 채택하지 않는다. 반대로 원인 미확정 상태를 연구 전체 무효로 확대하지 않는다.

로컬 전용 출력:
- 입력/코드 해시, 파일 계보, 가명화한 시행별 값과 저장값 대비 오차표
- 자료를 인수로 받는 재계산 스크립트와 재실행 명령
- 레벨별/전체 집계 및 근거가 있는 집계 방식 비교표

공개 가능한 출력:
- docs/reproducibility/initial_score_reconciliation_results_2026-11-04.md
- reports/reproducibility/initial_score_reconciliation_summary.json
- 개인정보·로컬 절대경로·원자료를 포함하지 않는 재계산 코드
- 기존 C02/복구 항목 상태는 실제 결과에 근거해 갱신하고 과거 기록을 지우지 않는다.

공개 저장소에 원 JSON, 좌표열, 참가자 식별자, 개인별 점수, 원자료 해시/절대경로를 커밋하지 않는다. 생성물 staging 전 git diff와 git status를 확인한다. 무관한 사용자 변경을 포함하지 않는다.

완료 조건:
1. 0.528/0.546/0.493/0.522/0.557 각각에 재현 여부와 근거가 표시돼 있다.
2. 표 7과 표 10의 연결, 초기 자료의 단위와 중복 처리가 설명돼 있다.
3. 원인 확정/계산만 재현/자료 부족이 구분돼 있다.
4. 명령 재실행과 의미 있는 집계 일관성 검사로 결과를 확인했다.
5. 논문 수정은 확정 근거에 따른 제안으로 제시한다. 원인을 확인하지 못했으면 해결했다고 쓰지 않는다.

## Codex CLI에 전달할 요청

이 문서를 읽고 알려진 로컬 연구 폴더에서 초기 사람 점수 불일치 조사를 수행해줘. 기존 원자료와 완료된 A/B·prod18 분석은 보존하고, 4세션·36 trial 후보의 실제 내용과 코드 계보를 먼저 확인해. 초기 가중치로 레벨별·전체 점수를 재계산하고 0.493과 0.557이 갈라지는 지점을 찾아줘. 조사 계획만 반복하지 말고 접근 가능한 자료로 실제 분석을 진행해. 결과는 위 산출물 형식으로 남기고, 공개 가능한 코드와 집계 보고서만 커밋해. 원인 미확정이면 필요한 파일과 이미 조사한 범위를 정확히 보고해. 새 실험과 논문 원본 수정은 이번 작업에 포함하지 않아.
