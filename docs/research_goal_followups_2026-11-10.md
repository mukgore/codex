## 3. 복수 해석이 문제인 조건과 반복 개선

- **판정 단위를 먼저 정한다.** 손가락·접촉·순서·횟수는 범주로, 굽힘·시점은 연속값 또는 허용 범위로 정의한다. 두 해석이 화면과 양립하고 그 차이가 채점에서 실제 탈락을 만들 때를 문제 후보로 본다. 허용 가능한 개인차, 보이는 정보가 같은 논리적 대안, 실제 참가자가 반복해서 고른 대안을 구분한다. AI 모델의 응답 분포도 별도 기록한다. 어느 집단의 응답 빈도만으로 논리적 복수 정답을 확정할 수 없다.
- **이해·확신도·모방을 분리한다.** 무가림·가림을 같은 원동작으로 비교하되 참가자에게 같은 원동작을 중복 노출하지 않는다. 영상 속 어떤 궤적을 봤는지는 자유 응답 후 공통 질문, 애니메이션 선택, 손 모형·타임라인 조절로 측정할 수 있다. 후보를 보여주기 전과 후의 응답을 분리하고, 확신도·판단 불가·가능 범위도 기록한다. 순서·최대 굽힘·그 시각을 따로 측정하고, 실제 따라 하기는 좌표·원본 타임스탬프와 점수를 모르는 평가자의 판정으로 기록한다. 동시 모방 조건에서는 해당 시점까지 보였던 단서를 기준으로 한다.
- **문제 인정과 예방.** 실험 전 허용 가능한 오답 집중도, 판단 불가 비율, 시점·굽힘 오차 및 표본 정밀도의 기준을 정한다. 무가림에서는 구별되지만 가림에서 동일한 대안으로 반복해서 갈리는지 확인한다. 대안 동작 쌍이 같은 가림 아래 구별되는지도 별도로 시험한다. 동작·가림 수정, 문제 제외, 사전 정의된 복수 답 허용 중 선택한다.
- **AI를 활용한 반복 개선.** 사람의 추정 정확도·확신도·오답 분포·실제 모방 결과를 보고 AI가 원인 가설과 다음 버전을 제안한다. 높은 확신의 공통 오답은 오해를 부른 구간, 낮은 확신의 분산은 부족한 단서, 정확한 추정 뒤의 낮은 모방 성과는 동작 수행 부담을 우선 검토한다. 첫 회차에는 원동작을 고정하고 가림 시점·범위 중 한 요인만 바꾼다. 새 참가자로 원본과 수정본을 비교하고, 최종 평가는 개선에 쓰지 않은 참가자·원동작에서 수행한다. 사람의 성공과 사람–AI 차이를 별도로 보고한다. | 새 실험에서 기존 방식 유경험자를 완전히 제외하기 어려움 | 무경험·유경험을 기록하고 조건 배정을 균형화한다. 같은 원동작 재노출을 줄이고 연습 과제와 본 과제를 분리한다. 전체 결과와 경험 여부별 민감도 결과를 함께 보고한다. |
| HaMeR가 MediaPipe보다 정확한 프레임도 MediaPipe 기준과 다르면 오차가 커지는 문제 | 무가림 원본에서 점수와 모델 출력을 모르는 복수 평가자가 대표 프레임에 랜드마크를 독립 주석한다. 가려져 확인 불가한 점은 표시한다. 두 모델을 같은 이미지 좌표와 해상도로 맞춘 뒤 독립 주석에 대한 오차와 모델 간 불일치를 따로 보고한다. 2D 주석으로 깊이 정확도를 판정하지 않는다. |
| 사람은 스마트폰 환경, AI는 고정된 영상 입력 | 같은 표시·카메라 조건의 통제 비교와 실제 스마트폰 사용성을 분리한다. 표시 장치·촬영 장치의 고정 여부를 따로 기록한다. 필요하면 손떨림 보정 후보를 비교하되, 실제 손 움직임과 프레임 시각이 달라지는지도 확인한다. |
| 사람은 추정 후 손으로 재현하고 AI는 좌표 추정만 함 | 공통 영상에서 사람의 좌표 찍기·손 모형 조작과 모델의 좌표 출력을 비교하는 추정 전용 과제, 카메라 모방 과제를 별도 시행한다. 좌표 찍기의 반응 시간은 해당 인터페이스의 시간으로 보고하고 카메라 모방 시간과 구분한다. 시점별 추정 비교와 연속 동작 평가는 각각 종점을 정한다. |

**진행 순서:** 기존 로그 재구성과 무가림 독립 주석 기준을 먼저 준비한다. 다음으로 소규모 파일럿에서 제시 방식, 답변 시간, 고정/스마트폰 조건, 경험 여부를 점검한다. 본 실험의 일정은 자료 사용권, 참가자 절차, 측정 환경, 목표 정밀도가 정해진 뒤 확정한다. 실제 시도 전 조건·정답 판정·분모·임계값 보정과 검증 분할을 기록한다.

## 5. 카메라·시각 접근성

카메라 사용이 어려운 경우 **가상 2D/3D 손 조작**, **관절 점 찍기**를 비교한다. 완료율·시간·오류·입력 부담을 측정하고, 시각 정보 자체를 이용하기 어려운 경우에는 별도의 비시각적 또는 대체 인증 경로가 필요한지 평가한다. 시각적 손 조작 UI는 카메라 접근성 실험과 시각 접근성 실험에서 구분해 평가한다. [실용성 V4](practical_validation_requirements_v0.3.md)

## 추가 실험 — 검정 원과 손가락색 원 비교

같은 원본 클립에 **무가림 / 검정 원 / 손가락색 불투명 원**을 만든다. 검정 원과 손가락색 원은 위치·반경·시간·불투명도·출력 인코딩을 동일하게 둔다. 손가락색은 대표 프레임의 피부색으로 클립별 고정한 단색을 먼저 사용하고, 사람과 조명에 따른 차이를 기록한다. 첫 비교에서는 프레임마다 색이 바뀌는 조건을 섞지 않는다.

MediaPipe Hands와 HaMeR의 버전·입력·설정을 잠근 뒤 동일 프레임에서 **검출 성공률, 공통 2D 랜드마크 오차, 검출된 프레임과 전체 프레임의 분모, 처리 시간**을 비교한다. 보이는 관절과 가려진 관절은 별도 집계하고, 독립 주석과 무가림 기준의 역할을 명시한다. 모델 차이와 가림색 효과는 같은 클립의 대응 결과로 보고한다. 모델에서 차이가 생겨도 사람이 그 가림을 더 잘 이해하는지는 별도의 사람 실험으로 확인한다.
