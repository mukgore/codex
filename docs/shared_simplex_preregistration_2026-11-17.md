# G03 공유 연결부 밖의 면 교차 보완 진단 — 사전등록 v1

기존 비공통 꼭짓점 면 SAT는 보존한다. 공유 꼭짓점/변을 가진 면 쌍의 교집합이 정상적인 공유 점/선분 밖으로 나오는지를 별도 버전으로 검사한다. 기존0지표가 전체 손의 비관통을 뜻하지 않는다는 제한을 보완하는 진단이다.

## 고정 대상과 방법

완료 TF-03 `tf03_path_20261116_v1`와 `tf03_path_record_20261116_v1`의 양손×seed7/19 네 경로, 경로당25프레임(0..3초), 총100프레임의778정점/1538면을 읽는다. 해당 setup의 원래 faces를 사용한다. 새 SDK 호출·난수·영상·원본 변경은0이다. 모델/샘플표면의 이전 판정과 새 보완 결과를 분리하고 풀/생체 승인은 하지 않는다.

전체 mesh 대각선으로 정규화하며 기존 공학 수치 허용값1e-7을 유지한다. topology에서 한 꼭짓점/한 변 공유 쌍을 빠짐없이 센다. 비공면의 공유 변은 평면 교선의 공유 선분만, 공유 꼭짓점은 두 삼각형의 평면 절단 구간 교집합을 검사한다. 공면에서는 세 변의 내부 반평면으로 볼록 절단한다. 교집합 꼭짓점이 공유 점/선분에서 허용값보다 떨어져 있으면 `NONLOCAL_OVERLAP_INDICATOR`다. 접촉/수치 지표이며 관통 깊이/부피는 아니다.

공면 경계의 부동소수 signed distance는 허용값 안에서0으로 취급한다. 평면 법선 외적 크기1e-12 이하는 공면 후보이며 잔차를 검사하고,1e-7 이하의 불안정 교선이나 근접한 비영 signed distance는 `NUMERICALLY_UNRESOLVED`로 남긴다. 퇴화 면은 기존 height/epsilon 기준으로 검사 불가다. 성공 수를 늘리기 위한 허용값 변경/재시도는 하지 않는다. 판정 불가가 있는 프레임은 보완 검사 clear가 아니다.

[CGAL 공식 intersection 계약](https://doc.cgal.org/latest/Kernel_23/group__intersection__linear__grp.html)의 삼각형 교집합 점·선분·삼각형·다각형 구분을2026-11-17에 확인했다. 이번 구현은 프로젝트의 독립 float 평면/절단 계산이며 CGAL 코드·exact predicate·검증된 CGAL 실행 결과가 아니다. 기존 GEO-01 SAT를 다른 알고리즘으로 소급 대체하지 않는다.

## 분모·오류·시간·해석

쌍/프레임의 정상 공유 연결부·비국소 지표·수치 미확정·퇴화를 모두 센다. 프레임별 쌍ID와 native epsilon·실제 wall/자체CPU는 비공개에 남긴다. 실행 예산1800초, 공유 쌍200,000개/프레임 상한이며 초과/실패/부분출력도 보존한다. 전체100프레임 journal과 source receipt 전후검산, 전체 worktree/입력/17pin CPU환경·실제 명령/시간/stdout/stderr/종료/출력hash를 새 immutable root에 기록한다. 실행 중 편집/커밋을 하지 않는다.

공유 면 보완 결과를 기존 비공유 면 검사와 분리한다. 샘플 사이 충돌·닫힌 부피 포함·물체/역학·임상 한계/사람 편안함은 남는다. 모든 자료는 비공개 영구 보관·연구 격리이며 모델/좌표/상세hash를 공개하지 않는다. 기존62ID·3D44요구·R0–R9와 실제 앞 단계 입력 우선을 유지한다.

사전 검사12개: 공유 변의 정상/같은 쪽 공면 겹침·공유 점의 공면 포함/반대 영역·비공면 절단구간·한쪽 평면·연결부 밖 접촉·모든 꼭짓점 순서/쌍 교환·이동/크기/회전/반사·불안정 평면·퇴화·topology 분모·잘못된 입력. 최초 정상 공면 접촉이 수치 판정 불가였던 반례를 경계값 처리로 수정한 뒤12검사를 통과했다. 이 검사는 새 MANO100프레임 계산과 별개다.
