# 공개 단서를 남기는 조건부 생성 — 2026-11-15

사용자의 재개 지시로 [실행 순서](../research_goal_followups_2026-11-10.md#실행-순서와-기존-백로그-연결)를 다시 확인했다. 등록 촬영21행의 원본 경로0개, 선별 응답 양식의 관측값0개다. 실제 촬영·독립 주석·사람 모방·운영 입력은 대기로 유지하고 가능한 독립3D 개발을 이어간다. 이 점검은 등록 접수 범위이며 전체 컴퓨터의 새 파일을 모두 조사했다는 뜻이 아니다.

## 실행 전 계획

[앞선 공통 카메라 실험](2026-11-15_shared_camera_and_mask_feasibility.md)에서는 양손 정렬을 고쳤지만 가림 조건이 모든 영상에서 불충족이었다. 기존 동시/순차 전체 굽힘은 거부 대조로 보존한다. 새 `non_target_cues_open` 프로필은 다음 두 원형을 비교한다.

- `middle_only_cues_open`: 중지 굽힘/복귀, 검지·소지·약지·엄지는 모델 중립 각도 유지.
- `middle_ring_cues_open`: 중지·약지 연동 굽힘/복귀, 검지·소지·엄지는 모델 중립 각도 유지.

seed7/19 × 두 원형 × 양손 × 저자 기본값/프로젝트 이상 반사 비교 =16후보, 각25프레임이다. 중립2개를 포함한 SDK 계산402개를 계획한다. 기존 프로필과 난수 하위흐름은 유지하고 새 원형은 별도 domain index를 쓴다. 원본 모델·학술 출처의 제약 구간을 수정하지 않는다. 중립 각도를 유지해도 shape/skin 연동과 투영 때문에 손끝 픽셀이 유지된다고 보장하지 않는다. 새 실제 좌표/표면/영상으로 확인한다.

각도·형상·시간 분포와 PIP/MCP/DIP 연동 비율은 기존과 같은 **공학 제안**이다. BIO-09 저자 모델 제약과 그 좌표 해석이 출처이며, 사람의 독립 손가락 제어·임상 한계·편안함의 근거가 아니다. 학술 근거와 현재 미확인 범위는 [색인](../academic_reference_index.md), [생체/랜덤 계획](../3d_biomechanics_and_random_generation_2026-11-14.md)에 유지한다. 실제 관찰 없이 생물학적 통과로 바꾸지 않는다.

## 선행 조건과 기록

1. 재현·양손/조건별 모델 제약·고정 단서 각도 검사를 먼저 한다.
2. 기존 CPU 환경과 비공개 모델 사용 범위로 새 SDK 계산·프레임별 삼각형 검사·무가림 영상·lossless decode를 실제 기록한다. 후보는 모두 격리한다.
3. 기록 검산 뒤 고정 중립 정렬·공통 카메라로 같은 Stage6/7 내부15%·외부10%·공개 손끝 최소2개·전 프레임100%와 기존 표면 proxy를 검사한다. 통과 가능한 후보만 정확한 ROI/codec 분기로 이동한다. 가림 크기를 임의로 늘리거나 조건을 낮추지 않는다.
4. 영상마다 UTC, 제안 시작→인코더 종료, 검산/저장 완료, 자체 CPU와 단계별 실제 시간을 보존한다. 공통 모델/카메라 준비와 실행 기록 봉인은 별도다. 실패·미실행과0초를 구분한다.

동일한 오른손 두 정책의 중복·같은 부모/seed·재렌더를 독립 family로 세지 않는다. 가림이 가능해도 임시 표면 정의·복수 정답·동작 추론·사람 모방·그림자/codec/송출/공격 관문은 별도다. prod UI는 변경하지 않는다. 새 촬영/사람 자료가 접수되면 앞 단계부터 처리한다.
