# S05 군집 사건의 동시 상한 구현 — 2026-11-17

사전지정 공격 유형과 legacy/candidate 두 채점 방식에 대한 일측 정확 이항 상한·Bonferroni 보정을 구현했다. [계약·가정·수식·CLI](../../validation_v03/SIMULTANEOUS_RISK.md), [코드](../../validation_v03/simultaneous_risk.py), [11검사](../../tests/test_simultaneous_risk.py)를 연결한다.

종점은 고정 유형/시도 예산 안에서 **한 군집의 어느 시행이라도 점수 수용되는 사건**이다. 반복 시행을 독립 표본으로 세지 않는다. 모든 test 행의 source/참가자/capture 연결을 만든 뒤 유형별로 나눈다. 오류·중단·부분 예산은 수용 가능 사건으로 보수 처리하고, 누락된 군집/유형은 상한1로 유지한다. 가정을 선언하지 않으면 추론 상한은 null이며 test 기준 탐색이나 실제 독립성 인증은 지원하지 않는다.

검증: 새11개+기존 군집8개+MediaPipe4개, 총23검사 통과. 분석적 꼬리확률·유한표본 포함률 검산과 잘못된 분모/연결/누락 반례, 실제 CLI의 fresh-output 동작을 포함한다. 실제 사람·모델 추론 실험을 새로 실행한 결과는 아니다.

S05에서 ‘최악 유형 동시 위험 상한 미구현’이던 엔지니어링 공백을 이 명시적 군집 종점에 한해 해소한다. 시행별 FAR·최종 인증 위험·미지 공격의 상한과 독립 실제 평가 완료는 주장하지 않는다. 실제 자료가 들어오면 사전 계획·표본·군집/권리·누출을 확인하고 기록 실행한다. 기존62ID/3D44요구/R0–R9와 우선순위는 유지한다.
