원래 handcaptcha checkout의 로컬 커밋 `acdcd78`에는 MANO 산출물과 Stage6/7을 연결하는 코드가 있었지만 당시 원격 작업 브랜치에는 포함되지 않았다. 현재 UI worktree에 `206f57d`로 옮겨 검토했고, `a154ad0`·`404cc04`로 입력 연결과 수치 검사를 보완했다. 초기 README의 존재하지 않는 과거 보고서 링크는 현재 기록으로 교체했다.

구현과 README의 최종 커밋은 handcaptcha `971c203`이며 지정 작업 브랜치에 push했다. 모델/원자료는 포함하지 않았다.

## 보완한 코드

- `load_bound_pilot`/`verify_pilot`: 영상·좌표·표면·보고서의 해시 연결과 전체 프레임 분모를 확인한다. 가림을 만들 자료뿐 아니라 기하에서 거부될 완료 자료도 같은 확인을 거친다. 검사/렌더 도중 파일이 바뀌거나 case 이름이 원본 보고서와 다르면 성공 summary를 남기지 않는다.
- `mask_feasibility`: 손목–중지 MCP 중점의 기존 원을 기준으로, 중지 관절을 가리면서 나머지 손끝 단서를 남기는 배율의 전 프레임 교집합을 계산한다. 계산 결과가 표현 범위를 넘으면 거부하고 유한한 구간에서만 제안한다. 실제 gate와 인코딩 검사는 별도로 유지한다.
- 검증/가림/codec 도구를 공개 코드로 정리한다. 라이선스 모델·참조 좌표·mesh 표면·원본 영상·각 파일 해시는 Git 밖에 유지한다. 기본 prod UI와 Stage6 수식은 변경하지 않았다.

## 명세 대비 남은 일

현재 모델 유래 손/가림 검사와 자체 capsule–sphere 접촉 fixture가 있다. 그러나 도입 관문 1에 적힌 **두 종류의 제한된 grasp와, 2D 보간이 구분 못하는 쌍·3D 제약도 구분 못하는 쌍을 모두 갖춘 대조**의 충족은 아직 확인되지 않았다. 기존 굽힘/PCA 조건 여러 개를 그 완료 증거로 세지 않는다. 다음 독립 작업은 이 구체적인 공백을 기존 fixture와 대조하는 것이다.

생체 가동 범위·손/물체 표면 관통·사람의 실제 편안함·복수 정답·강한 A2/A3 공격·보호 동작까지의 비교·운영 자산 권리는 별도다. 두 관절의 2D 기하 관문을 통과했다고 실제 관절 전체가 가려졌다고 판단하지 않는다. 반경 제안은 source별 공학 제약이며 일반 weight나 검증된 CAPTCHA 기준이 아니다.

원래 우선순위의 새 촬영 21개·독립 주석/동의한 사람 응답·실제 대응 모방/정지·HaMeR/Text2HOI checkpoint/config·허용 runtime·운영 환경은 계속 필요하다. 새 실험 결과를 대신 만들지 않는다.
