# MANO 원래 회전축과 BMC 각도 반응의 국소 진단

## 마무리한 작업

기존 비공개 MANO와 설치된 CPU 환경으로 양손의 flat mean 자세를 기준 삼아, 각 관절의 원래 axis-angle 좌표를 한 축씩 ±0.02radian 바꿨다. 한 손마다 중립1개와15관절×3축×정/반대90개, 총182개 자세를 새로 계산했다. 이 값은 공학 진단용이며 생체 허용 범위나 안전한 움직임으로 정한 수치가 아니다. 자세 순번은 시간이 아니므로 속도/가속도를 계산하지 않았다.

PCA를 끄고45개 local axis-angle 입력을 사용했다. 반환된48개 full pose에서 root3개가0이고 나머지45개가 입력과 정확히 같은지, 원래16관절의 부모 표와 canonical21점 대응을 확인했다. 모델·계수/좌표·반응 행렬은 비공개로 보존한다.

원래 축의 변화가 BMC의15개 굽힘/벌림 쌍에 미치는 전체 반응을 보존했다. 차분에서는 flexion의±pi branch를 처리했다. 반응은 `BMC 각도 변화 / 입력 회전 변화`이며 초당 속도가 아니다. 단일 BMC 쌍의2개 값만으로3개 원래 회전 좌표를 유일하게 복원한다고 가정하지 않는다. 아래 관절/표면의 다른 정보까지 모두 관측 불가능하다는 결론도 내리지 않는다.

## 학술 근거와 적용 한계

[BIO-01 MANO·BIO-02/03 BMC](../academic_reference_index.md)와 공개 SDK의 원래 pose API/부모 관계를 연결한 **모델 좌표계 진단**이다. 기존 [D-H/수정D-H 참고 모델](2026-11-15_kinematic_conventions.md)과 달리 실제 MANO forward를 사용했으나, MANO native x/y/z가 임상 굽힘/벌림 축이라는 검증은 아니다. API의 원래 회전 좌표를 사용했으며 모델 파라미터를 역추정하거나 가중치를 추출한 작업은 아니다.

중립 부근의 유한차분 행렬을 전체 자세 영역의 고정 변환으로 쓰지 않는다. 임상 중립/축·엄지·실제 손가락 기저/wrist offset·twist·SI단위/허용 영역은 남는다. 표면 손끝과 pose-dependent 변형은 고정된 관절 중심과 구분한다. 자기/물체 충돌·역학·사람의 편안함·최종 가림 영상·생체 프로필 적용·문제 풀 채택은 이번 범위에 없다. 기존 여섯 한계와 랜덤8개 격리는 유지한다.

## 코드·검사·실행 기록

생산 코드 `faf9c3b`의 `analysis/runtime_benchmark/mano_axis_probe.py`, 기존 hand feature 코드 `5c13624` 이후 수치 구현을 사용했다. 설계91개/45좌표·정/반대 축·thumb parent index·알려진 회전/비자식 불변·각도 wrap 검사4개를 추가했다. 연구 전체206개 검사 통과.

실제 외부 기록은52입력·코드·기존 CPU17pin 환경과 명령/시각·종료/출력을 연결했다. `EXITED_ZERO`, 전후 snapshot 일치, 산출물12개 재검사 통과다. [공개 집계](../../reports/mano_axis_probe_20261115.json). 로컬 `private_artifacts/mano_axis_probe_20261115/`, `mano_axis_probe_record_20261115/`, `mano_axis_probe_config_20261115.json`에 상세 자료를 보관하며 Git에는 코드·집계만 넣는다. 새 설치·외부 업로드·카메라·GPU/Colab은 사용하지 않았다.

## 중단 시점과 재개할 일

사용자의 지시에 따라 이 단위의 기록/커밋/브랜치 반영 후 작업을 중단한다. 이 단위의 모델 계산·검사는 정상 종료했으며 새 실험을 시작하지 않는다. 다음에는 현재 반응 행렬과 실제 neutral·해부학적 축/엄지·wrist 기준을 학술/측정 근거로 대응하고, 전체 자세/복합 회전과 허용 프로필을 검토해야 한다. 단일 축 진단을 임상 축 보정 완료로 설명하지 않는다. 실제 촬영/선별·정상/정지 대응 입력이 접수되면 [원래 실행 순서](../research_goal_followups_2026-11-10.md)를 먼저 따른다.
