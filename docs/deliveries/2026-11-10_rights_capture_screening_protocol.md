# 사용 범위 확인·통제 촬영 접수·사람 선별 실행안 v0.1

**이후 진행:** 사용자는 촬영 입력이 없어도 다른 단계의 가능한 작업을 계속하도록 요청했다. [전 단계 실행 결과](2026-11-10_all_stage_execution.md)에 실제 MediaPipe 가림색 비교·로그 재구성·채점/서버 회귀와 남은 입력을 기록했다. 이 문서의 새 사람 선별 계획은 여전히 실제 수집 전 초안이다. UI 수정 단계 전까지 화면·설계는 handcaptcha prod를 따른다.

[1단계 기록과 촬영 목록](2026-11-10_stimulus_intake_and_capture_list.md)을 이어서 실행했다. 연구 성능 결과는 아직 없다. 기존 원본의 연구 사용 근거는 사용자 진술로 확인했고, 신규 촬영 접수 양식·사람 선별 절차·배정안은 준비했다. 실제 촬영, 제3자 동의, 참가자 모집과 응답 수집은 실행하지 않았다.

## 1. 사용권 확인 결과와 보관 방침

2026-11-10 사용자는 기존 baseline/custom 등 손 영상에 대해 **본인이 촬영했고 본인의 손**이라고 확인했다. 이어 보관 방침을 **비공개 상태로 영구 유지**로 지정했다. 현재 연구 진행 요청을 포함해 다음 범위로 기록한다. 이는 독립적인 소유권 감정이나 다른 자료의 허가가 아니다.

| 항목 | 이번 처리 | 남은 경계 |
|---|---|---|
| 기존 본인 촬영 영상의 촬영자·손 수행자 | 사용자 본인이라는 자기 진술 확인 | 타인 촬영물·외부 모델 자산·새 참가자 자료에 확대하지 않음 |
| 연구 분석·좌표 추출·가림 파생본 제작 | 현재 작업 요청 범위에서 허용으로 기록 | 운영 서비스 이용허락과 분리 |
| 보관 기간 | 원본·파생본·연구 기록은 비공개 영구 보관, 자동 삭제 예정 없음 | 이전 제안의 90일 삭제는 채택하지 않음 |
| 접근 | 사용자와 현재 작업에 승인된 로컬 처리. 새 연구 담당자는 별도 지정 | 원본·정답·연결표를 공개 저장소/공유 링크로 제공하지 않음 |
| 연구 참여자 제시 | 동의한 연구 참여자에게 필요한 파생 자극만 제시하는 절차 준비 | 아직 참가자/접근자 미지정, 실제 제시 미실행 |
| 공개 배포·재배포·상용 서비스·외부 서비스 업로드 | 이번에는 허가받은 것으로 기록하지 않음 | 필요하면 목적별 별도 허가 |
| 운영 승격 | `release_allowed=false` 유지 | 연구 사용 근거 확인이 운영 전체 승인으로 이어지지 않음 |

대장은 저장소 밖 `deliverables-review/private_artifacts/screening_packet_20261110_v1/rights.private.json`에 보관했다. 사용자 실명·서명·연락처를 새로 수집하지 않았다. 기존 `pair.private.json`의 `UNREVIEWED`는 제작 당시 스냅샷이므로 덮어쓰지 않는다. 현재 연구 사용 범위는 이번 대장을 함께 참조한다. 원본 1개의 알려진 개발 자료라는 분류와 과거 공개 노출 이력은 그대로다.

이번 증거 탐색은 handcaptcha checkout의 README·추적 파일 및 `private_artifacts/handcaptcha`, 기존 CAPTCHA 자료의 동의/권리/라이선스 관련 파일명 범위다. 별도 동의 파일은 이 범위에서 찾지 못했고, 사용자 응답으로 본인 자료의 연구 사용 근거를 보완했다. 코드 공개나 코드 라이선스를 영상 사용권 증거로 대신하지 않았다.

## 2. 통제 촬영 접수와 품질 판정

기존 A01–A06의 18파일을 먼저 촬영한다. **접촉 유무 자체의 대안쌍**까지 시험하려면 A07을 3파일 더 촬영한다. 따라서 이번 전체 선별 배정안에 필요한 원본은 **7개 지시×3 take=21파일**이다. A07이 없으면 접촉 유무의 대안쌍 실험은 준비 미완료로 둔다.

| 추가 ID | 동작 | 구도·시간 | 반복 |
|---|---|---|---:|
| A07 | A06과 같이 엄지·검지를 접근시키되 두 끝을 맞대지 않고, 화면에서 구별되는 작은 틈을 남긴 뒤 원위치 | A06과 같은 엄지 쪽 30–45° 고정 구도. 0–2초 시작, 2–6초 접근·복귀, 6–8초 끝 자세 | 3 take |

A06과 A07의 차이는 손끝 사이의 접촉/틈이다. 틈 크기는 원본에서 확인할 수 있게 촬영하고, 가림에서 모호해지는지는 결과로 판단한다. 접촉 압력·깊이는 2D 영상만으로 정답이라고 확정하지 않는다. A06/A07은 같은 F04 계열이다. A01=F01, A02/A03=F02, A04/A05=F03으로 묶으며 반복·가림색·수정본도 같은 계열을 공유한다.

### 원본 하나를 받을 때 처리할 순서

1. 원파일을 비공개 raw 경로에 복사하고 원래 파일은 보존한다. 촬영 ID·take·촬영자/수행자 코드·사용 근거·구도·기기·반전 여부·원파일 해시를 연결한다. 인적 연결표는 영상 manifest와 분리한다.
2. `ffprobe`로 해상도·stream·프레임 수·PTS·길이를 확인하고 전 프레임을 디코딩한다. 30fps는 촬영 권장값이지 다른 정상 FPS를 탈락시키는 기준이 아니다. VFR이면 실제 PTS를 쓰며 처리기가 지원하지 않으면 보류한다. 오디오가 있으면 원본은 보존하되 제시본에서 제거한다.
3. 손끝·손목 잘림, 초점/노출 변화, 프레임 손상, 자동 미러/크롭, 불필요한 얼굴·식별 배경을 확인한다. 동작 구간과 시작/끝 유지가 보이는지 사람이 확인한다. 추적 성공만으로 통과시키지 않는다.
4. 촬영 지시와 실제 동작을 분리해 기록한다. 검지·중지의 자연 연동은 숨기지 않고 실제 허용 범위를 기록한다. 원본에서 손가락/순서/횟수/접촉을 판정 못 하면 가림을 만들기 전에 구도나 동작을 수정한다.
5. QC가 통과한 **가장 이른 take 번호** 하나를 각 동작의 첫 제시용으로 선택한다. 사람 결과를 본 뒤 잘 나온 take로 바꾸지 않는다. 나머지는 예비·재현 확인용이며 독립 test가 아니다.
6. 같은 원본에서 무가림/검정/고정 피부색 조건을 같은 시각·인코딩으로 만들고, 가림 위치·반경·불투명도와 최종 프레임·PTS를 검사한다. 원본·정답 좌표는 참가자에게 전달하지 않는다.

판정은 `READY_FOR_ANNOTATION` / `RETAKE` / `TECHNICAL_HOLD` / `RIGHTS_HOLD`로 남긴다. 잘못 찍은 원본도 연구 기록으로 비공개 보존하고 실패 사유를 남긴다. 아직 새 원본이 없으므로 접수 대장 21행은 모두 `AWAITING_CAPTURE`다. 빈 파일 경로나 촬영 날짜를 임의로 채우지 않았다.

## 3. 사람 선별 과제와 참가자 조건

여기서 선별 대상은 **사람의 우열이 아니라 영상 문제**다. 참가자 조건은 과제를 해석할 수 있는지, 기존 노출이 있는지, 필요한 동의가 있는지를 기록하는 용도다. 카메라 모방 능력·손 운동 능력은 이번 해석 전용 과제의 참가 조건으로 요구하지 않는다.

- 과제 설명을 이해하고 참여에 동의한 사람으로 시작한다. 언어·보이는 영상 크기·화면 확인 가능 여부를 기록한다. 이번 방식으로 영상을 볼 수 없는 경우를 낮은 해석 성능으로 세지 말고 접근성 경로 필요로 기록한다.
- 기존 CAPTCHA 경험, 공개 custom 문제 또는 해당 원본/가림본을 본 적이 있는지 사전 질문한다. 촬영자·자극 제작자·정답 주석자는 답을 아는 사람이므로 주 선별 표본에 포함하지 않는다.
- 같은 family를 본 사람은 그 family의 처음 보는 조건 분석에서 제외해 별도 노출군으로 남긴다. 배정 뒤 발견된 노출도 기록하고 전체 배정 분모에서 조용히 삭제하지 않는다.
- 첫 회차의 모집 범위는 성인 동의 가능 참가자로 제안한다. 미성년자를 포함하려면 기존 문서대로 학교/연구자 절차를 먼저 확정한다. 이 문서가 그 절차나 실제 동의를 대신하지 않는다.
- 사용자 외에 실험 담당자·자료 접근자·참가자에게 보여 줄 연락 창구는 아직 지정되지 않았다. 다른 사람에게 연락하거나 모집 메시지를 보내지 않았다.

### 참가자 안내·동의 양식에 넣을 내용

“이 과제는 가려진 손 영상에서 동작을 어떻게 해석하는지 알아보기 위한 연구입니다. 영상 설명, 손가락·접촉·순서·횟수 답변, 확신도, 판단 불가, 응답 시간과 오류를 기록합니다. 이번 해석 과제는 참가자 손 영상을 촬영하지 않습니다. 기록은 연구용으로 비공개 영구 보관하며 자동 삭제 예정은 없습니다. 참여 여부와 중단은 자유이고, 모르는 문제는 판단 불가로 답할 수 있습니다. 공개 배포·상용 사용·외부 서비스 업로드는 이번 동의에 포함하지 않습니다. 담당자·접근자·연락 방법과 철회 시 처리 범위를 확인한 뒤 참여를 결정해 주세요.”

실제 양식에는 `consent_version, participant_code, explanation_date, affirmative_consent, indefinite_private_retention_acknowledged, withdrawal_contact, researcher, access_roles`를 채운다. 영구 비공개 보관에 동의하지 않은 사람에게 동일 동의를 강요하거나 몰래 다른 기간을 적용하지 않는다. 대안 보관 조건을 채택하려면 별도 버전으로 기록한다. 철회 시 향후 사용 중단, 연결 가능한 개별 기록의 삭제 요청 처리, 이미 비식별 집계된 결과의 처리 범위를 참여 전에 설명한다. 현재 담당자·연락 창구가 빈 상태이므로 실제 동의를 완료 처리하지 않는다.

## 4. 원본 독립 주석과 응답 순서

촬영 지시를 알고 있는 제작자와 별도로 평가자 2명이 무가림에서 보이는 동작을 독립 주석한다. 모델 출력·채점 점수는 보여 주지 않는다. 필요한 기준 프레임/시각과 확인 불가를 남기고, 불일치는 합의/제3자 검토로 정리한다. 불일치가 남으면 해당 자극은 `INCONCLUSIVE_REFERENCE`이며 참가자 오답으로 몰지 않는다.

주석 항목은 움직인 손가락, 접촉 유무(해당하는 경우만), 동작 순서, 반복 횟수다. 굽힘 범위와 최대 굽힘 시각은 별도 기록한다. 2D 화면에서 확인 못 하는 접촉·깊이·관절각은 추정 정답을 만들어 넣지 않는다. 허용 가능한 개인차·대안 해석과 그 이유를 **참가자 응답을 보기 전에** 정답표에 적는다. 필요한 항목이 보이지 않으면 재촬영한다.

한 시행은 준비 확인→고정 영상 1회 재생→자유 응답→공통 질문→확신도(1–5)/판단 불가→필요한 선택지 후 응답 순서다. 자유 응답 후 60초를 두고, 공통 질문도 60초를 두는 제작 파일럿 기본안을 사용한다. 응답 시간은 영상 끝 기준으로 기록하며, 선택지 후 답은 최초 해석 정답률에 합치지 않는다. 추가 재생 요청은 별도 기록하고 그 뒤의 답도 최초 1회 결과와 분리한다. 실제 영상 재생/응답 수집 UI는 아직 구현하지 않았다.

**주 종점:** 선택지를 보기 전 자유 응답과 첫 공통 질문에서, 사전 주석한 해당 범주 항목 전체를 맞힌 시행의 비율. 손가락/접촉/순서/횟수를 각각도 보고한다. 확신도·판단 불가·굽힘·시각 오차·답변 시간은 별도다. 굽힘·시간의 허용 오차는 이번 범주 선별의 합격 조건에 임의로 추가하지 않으며, 그것이 중요한 문제는 별도 사전 기준이 생길 때까지 보류한다.

## 5. 소규모 배정안과 사전 판정 규칙

**계획 슬롯 36개, 각 4시행=144시행**을 준비했다. 모집 인원 확보나 표본 정밀도 승인을 뜻하지 않는다. 12슬롯씩 무가림/검정/피부색 조건에 배정하고, 한 사람은 각 family에서 한 동작만 본다. F02는 A02/A03, F03은 A04/A05, F04는 A06/A07을 절반씩 나눈다. A01은 조건당 12슬롯, 나머지는 각 동작·조건당 6슬롯이다. take 3개를 3명으로 세지 않는다.

슬롯은 참가자 ID가 없는 계획이다. 실제 배정 전 경험 유무별 명단 안에서 무작위 배정하고 세 조건의 수를 맞춘다. 경험군 수가 불균형하면 기록하고 원래 계획과의 차이를 보고한다. 시간 순서대로 원하는 조건을 고르게 하거나 정답을 아는 사람을 빈 슬롯에 넣지 않는다. 공개 계획에는 참가자 식별자·정답·원본 경로를 싣지 않는다.

다음 숫자는 **후보 영상을 추리는 파일럿 v0.1의 공학 기준안**이다. 본 연구나 CAPTCHA 운영 합격 기준이 아니다. 실제 수집 전에 담당자가 프로토콜 버전·자극/정답표·배정·판정표를 날짜와 함께 잠가야 한다. 현재 원본/담당자가 없어 `DRAFT_NOT_ENROLLED`다. 관측 뒤 기준을 바꾸면 새 버전·새 참가자로 평가한다.

| 검사 | 사전 규칙안 | 조치 |
|---|---|---|
| 기준 원본 | 독립 주석 불일치/확인 불가가 남거나, 무가림 범주 정답률 90% 미만 | 원본·구도·주석을 수정. 가림 효과로 해석하지 않음 |
| 평가 가능 수 | 동작×조건마다 사전 정답표와 비교 가능한 처음 노출 응답 6개 미만 | `INCONCLUSIVE_SMALL_N`. 새 시행이 필요하면 기존 실패·배정 분모를 유지한 추가 계획 작성 |
| 명확한 영상의 소규모 진단 진입 | 무가림과 해당 가림에서 범주 정답률 각각 90% 이상, 판단 불가 10% 이하, 해결 안 된 논리적 대안 없음 | 해당 조건만 `ELIGIBLE_FOR_3A_DIAGNOSTIC`. 6명이면 6/6, 12명이면 11/12 이상 필요 |
| 반복 대안 후보 | 같은 대안이 가림에서 2명 이상에게 나오고, 무가림에서는 그 대안 0명 | `REVIEW_AMBIGUITY`. 원본과 양립하는지·허용 답 밖인지 평가자가 검토. 빈도만으로 복수 정답 확정 금지 |
| 해석은 맞으나 확신 낮음/시간 큼 | 확신도·시간 분포와 응답 내용을 검토 | 합격 기준을 뒤늦게 바꾸지 않고 단서/부담의 후속 후보로 기록 |
| 기술 오류·중단 | 모든 배정 시행에 별도 상태 유지. 어느 동작×조건에서든 10% 초과 | 기술 문제를 우선 수정하고 해당 셀의 선별 판정 보류. 오답/거부 성공으로 세지 않음 |

90%·10%·반복 2명은 이번 진단용 제안값이며 기존 문서에서 검증된 수치가 아니다. 표본 수 6에서 전원 정답이어도 일반적인 95% Wilson 구간 하한은 약 0.61이므로 높은 모집단 정확도를 입증하지 못한다. 3A로 가더라도 소수 문제의 점수/정지 진단이라는 주장에 한정한다. 본 실험의 목표 정밀도·최소 의미 차이·참가자/family 군집을 반영한 표본 설계는 후속으로 남긴다.

주 비율의 분모는 배정 시행 전체다. 판단 불가는 정답 0으로 포함하고, 기술 오류·중단·사후 노출 발견은 별도 건수와 함께 전체 비율 및 비교 가능한 응답만의 비율을 나란히 보고한다. 군집 단위는 사람과 source family다. frame·같은 take 파생본은 독립 표본이 아니다. 전 조건의 원자료를 합쳐 가림색 우열을 확정하지 않고 같은 동작 조건별 결과를 보고한다.

## 6. 만든 파일과 다음 단계 선행 조건

[준비 코드](../../analysis/prepare_screening_packet.py)는 private 폴더에 권리 대장, 21개 촬영 접수 행, 36개 계획 슬롯·144개 시행 순서, 빈 응답 양식을 만든다. 참가자·동의 서명·정답·관측값을 생성하지 않는다. 각 슬롯의 family 중복 0과 동작×조건 배정 수를 자동 검산했다.

```powershell
python -m analysis.prepare_screening_packet --output ../private_artifacts/screening_packet_NEW
```

| 항목 | 완료 | 필요한 입력 |
|---|---|---|
| 기존 본인 자료의 연구 사용·보관 방침 | 사용자 진술 확인, 비공개 대장 기록 | 별도 타인/외부 자료를 쓰려면 그 자료의 근거 |
| 통제 촬영 | 21개 접수 행·QC·take 선택 규칙 준비 | A01–A07 실제 원파일·촬영 설정 |
| 사람 선별 | 주 종점·응답/주석 양식·배정·진단 기준안 준비 | 담당자/접근자/연락 창구 지정, 사전 잠금, 제3자 실제 동의·원본 독립 주석·응답 |
| 1→2단계 | 기존 원본의 연구 사용권 미확인 상태는 해소 | 새 원본 QC와 가림 조건 제작 후 실제 2단계 선별 |
| 2→3A | 작은 진단의 진입 기준 명시 | 위 기준을 충족한 실제 영상·해석 결과. 아직 승인 영상 없음 |

신규 촬영이나 사람 응답을 대신 만들 수 없으므로 현재는 **사용권·보관 확인 완료, 촬영·사람 선별 준비 완료, 실제 수집 대기**다. 사용자의 본인 촬영 확인을 제3자 참가자의 영구 보관 동의로 대신하지 않는다.
