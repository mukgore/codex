# MANO 원래 관절과 실행 기록을 남기는 새 생산 경로

기존 사용자가 제공한 모델과 설치된 CPU 환경으로 양손 flat-mean PC1 동작을 새로 실행했다. 각 24프레임, 총 48프레임의 모델 forward·렌더·재decode를 완료했다. 양손 모두 이전 파일럿의 표면 정점·21점·PCA 입력과 배열 값이 정확히 일치했다. 과거 생산자 코드 바이트를 복구했다는 뜻은 아니다.

## 완료한 일

- 모델 원래 관절 16개, named mesh 손끝 5개, canonical 21점의 출처를 구분했다. 원래 부모 표, 48차원 axis-angle, PCA 입력, 표면, 카메라 투영을 비공개로 저장했다.
- 새 코드 `5b4cf85`, 읽기 의존성 수정 `ebdfcb8`을 기준으로 실제 명령·시각·종료·입력/SDK/환경 snapshot·출력 목록을 연결했다. 결과는 [요약 JSON](../../reports/mano_controlled_producer_20261114.json)에 있다.
- 48프레임 모두 feature 계산 가능했다. 연구 코드 전체 193개 검사, hand pipeline 전체 138개 검사와 마지막 읽기 회귀를 포함한 bridge 8개 검사가 통과했다.
- 처음 실행은 저장 자료 읽기가 MediaPipe를 간접 import하여 모델 실행 전에 실패했다. 해당 실행 기록을 보존하고 읽기 기능의 의존성을 지연시킨 뒤 새 v2 경로에서 실행했다. 추가 설치나 기존 환경 변경은 없었다.
- v2 실행 종료는 `EXITED_ZERO`, 전후 snapshot 일치, journal 48/48 `COMPLETED`, 산출물 재검사 통과다. 손 미리보기도 로컬에서 확인했다.

## 저장 위치와 범위

로컬 `deliverables-review/private_artifacts/` 아래 `mano_controlled_producer_20261114_v2/`에 생성 자료, `mano_controlled_producer_record_20261114_v2/`에 실행 증거, `mano_continuing_research_scope_20261114.private.json`에 이전 사용자 제공/비공개 CPU 연구 기록 연결을 보관한다. 처음 실패 기록은 접미사 없는 record 폴더에 남는다. 모델·좌표·영상·상세 입력 hash는 Git에 올리지 않는다.

기존 동봉 라이선스와 intake를 변경하지 않았다. 계속되는 비공개 비상업 연구 범위를 기록했으며 운영/상용 허가나 새 서명 동의로 해석하지 않는다.

## 아직 필요한 입력과 다음 순서

이 동작의 진폭 0.8은 기존 공학 재현값이다. 생물학적 허용 범위가 아니며 랜덤 동작을 뽑지 않았다. 물리 SI 단위, 엄지를 포함한 해부학적 의미/관절 범위·연동·속도 근거, 자기 충돌과 실제 수행 가능성은 미확인이다. 표면 손끝은 관절 중심과 구분하며 모든 20개 선분에 고정 뼈 길이를 강제하지 않는다.

다음은 이 출처 구분을 유지한 제약 프로필·제한 랜덤 생성과 거부 기록이다. 허용 수치가 없는 상태를 통과로 바꾸지 않는다. 원래 실행 순서의 통제 촬영·선별·실제 대응 실험 입력은 계속 우선이고 이번 독립 개발로 선행 조건을 충족했다고 보지 않는다. 전체 목표는 진행 중이다.
