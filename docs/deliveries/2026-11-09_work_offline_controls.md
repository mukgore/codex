## 1. 공개 8개 문제의 좌표 대조

[실행 코드](../../analysis/coordinate_controls.py)와 [조건별 집계](../../reports/coordinate_controls/known_source_2026-11-09.json). 같은 기준 좌표를 기존 HTML의 점수·오프라인 자세 관문과 후보 특징에 입력했다. 기준 좌표 그대로의 입력 외에 진행 위치 `p + 0.10 sin(πp)`로 재표본화한 정방향 응답을 추가했다. 시작과 끝은 같고 자세 순서는 유지된다. 이 비교는 초기 exact 대조 이후 추가한 탐색이며 사람의 실제 모방 오차를 모델링하지 않는다.

| 입력 | 기존 점수 통과 | 점수·관문 모두 통과 | 정방향 속도 변형보다 오차가 큰 건수, 각도 MAE / DTW 각도 RMSE / 가속도 MAE |
|---|---:|---:|---|
| 기준 좌표 그대로 | 8/8 | 8/8 | 0 / 0 / 0 |
| 정방향 속도 변형 | 8/8 | 8/8 | 비교 기준 |
| 첫·중간·끝 자세 정지 | 24/24 | 16/24 | 24/24 · 24/24 · 3/24 |
| 시작과 끝 사이 보간 | 8/8 | 8/8 | 8/8 · 8/8 · 1/8 |
| 역재생 | 8/8 | 6/8 | 8/8 · 8/8 · 8/8 |
| 다른 동작 | 56/56 | 37/56 | 56/56 · 56/56 · 47/56 |
| 가운데 한 프레임 누락 | 8/8 | 8/8 | 완전 연속 구간 비교 가능 0/8 |

각도 MAE는 동작 진행률을 맞춘 15개 각도의 평균 절대차다. DTW RMSE는 시간 순서를 보존하는 제한 정렬을 적용한 후의 각도 오차다. 가속도 MAE는 손목·크기를 정규화한 좌표의 시간 미분을 비교한다. 여기서 시간은 영상의 명목 FPS에 따른다. 기존 **연속 점수도** 누락 외의 위 오답 96건에 정방향 속도 변형보다 낮은 점수를 부여했다. 따라서 각도 특징이 기존 점수보다 우수하다고 판정할 수 없다. 기존 임계값 0.25는 이 오답들을 거르지 못했다. 가속도 오차는 정지나 보간 응답에 대해 대체로 더 작았으므로 단독 기준으로 삼을 근거가 없다. 한 프레임 누락 비교는 후보 점수가 0이라는 뜻이 아니라 완전 연속 입력에 한정된 현재 비교기가 결과를 반환하지 않았다는 뜻이다.

오답 96건은 같은 공개 문제에서 만든 반복 조건이며 독립 사람이나 원동작 104개가 아니다. 후보 특징의 가중치·임계값은 맞추지 않았다. 카드 D에서는 정적 사진·정지 손·정상 모방·오답의 실제 카메라 입력에 기존 점수와 두 각도 특징을 같은 시행 단위로 기록해야 한다. 카드 E는 권리가 확인된 미사용 원동작과 대응 자료를 확보한 뒤 저장 답 재사용과 처음 보는 문제를 비교한다. 기존 점수 및 자세 관문의 기준은 그대로 사용했다.

## 2. 기존 G4와 픽셀 진단 재현

G4 136건을 기존 HTML과 로컬 보호 동작에 다시 연결했다. 기존 공개 집계의 11개 조건별 시도 수·점수·관문·검증·로컬 보호 동작·정지 필터와 평균 점수가 모두 일치했다. 별도 Python 검산에서 점수·점수 통과·관문 통과 불일치가 각 0/136이고 점수 최대 절대 오차는 2.22e-16이다. 시간은 회귀 비교에서 제외했다.

MediaPipe 0.10.14와 OpenCV 4.10.0으로 기존 26개 저장 영상 조건을 다시 실행했다. 공개 가림 8개 영상의 16조건 집계는 동일했고, 보존 원본 1개의 가림·무가림 10조건은 검출·점수·관문이 일치했다. 각도 특징 등 부동소수점 값도 절대 허용오차 1e-9 안에서 일치했다. 무가림 가운데 프레임 반복에서 관측된 약 30.34도/초는 실제 움직임이 없는 입력에 대한 추적기 출력 변동이다.
