## 출처와 적용 범위

BIO-09의 [고정 저자 코드](https://github.com/lixiny/manotorch/blob/a2a70c591f91551078b7bb2af9b5d9f275b626e0/manotorch/anatomy_loss.py)에서 `AnatomyConstraintLossEE.setup`, `_cal_loss_one_axis`, `forward`를 확인했다. 원본 Git blob 바이트와 일치하는 비공개 소스와 LICENSE를 보존했다. 여섯 관절군·세 축의 기본 구간, native joint 배정, 결과 순서와 `1e-6`라디안 영 근처 mask를 AST에서 추출했다. [공개 출처/구간 JSON](../../references/manotorch_default_constraint_extraction.json)의 ID는 `BIO-09-IMPL-DEFAULTS`다.

증거 등급은 **저자 구현의 모델용 제약**이다. 개별 수치의 원측정·대상·과제 근거는 미확인이다. 이를 2021 원논문 전체의 재현, 사람의 보편적인 가동 범위, 임상 안전 한계 또는 BMC의 두 각도 허용 영역으로 간주하지 않는다. `thumb_pip`는 소스 이름을 보존한 모델 엄지의 마지막 관절15다.

정확한 구간 초과량과 저자 mask를 반영한 유효 손실을 별도로 계산했다. mask는 초과량이 아니라 원래 각도의 절대값이 `1e-6`보다 큰지로 적용된다. 큰 각도에서 작은 초과가 생기면 임의로 무시하지 않는다. source 기본값은 수정하지 않았다.

## 좌우 비대칭의 별도 대조

이상적인 반사 기준축의 관계에서는 intrinsic XYZ 각도가 `(-x,-y,z)`로 대응한다. 별도 합성 각도 대조에서 엄지 관절13의 벌림+30도는 기본 구간 안, 반사한-30도는 같은 소스 기본값에서15도(약0.2618라디안) 초과였다. 다른 각도는0이다.

이 대조는 실제 두 메시의 fitting이나 사람의 좌우 차이 측정이 아니다. 비대칭 기본값을 양손에 적용할 때 부호/방향 해석을 따로 검토해야 한다는 좌표계상의 확인이다. 저자 코드의 오류나 생물학적 비대칭을 확정하지 않았으며 값을 자동 반전·완화하지 않았다.
