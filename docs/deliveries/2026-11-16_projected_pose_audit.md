# TF-02P 수정된 자세의 원출력 검산 — 2026-11-16

[무수정 PCA 제안](2026-11-16_template_free_pose_pilot.md)의 B32개가 모두 모델 prior에서 거부된 뒤, [새 사전등록](../tf02_projected_pose_preregistration_2026-11-16.md)에 따라 동일32제안의 해부학적 Euler값을 고정 저자 모델 구간에 투영했다. 분포·epsilon·허용 구간을 바꾸지 않았으며 새 난수·원형·시간곡선은 없다. 투영은 프로젝트 공학 수정법이고 임상 연동이나 학습된 자세 분포의 보장은 아니다.

## 실행 상태를 구분한 증거

생산자는 SDK34회(수정32+양손neutral2)와32사례 저장을 끝냈다. 이후 최종 요약에서 `surface_state` 필드 누락으로 `PROCESS_ERROR`가 됐다. 당시 전후 snapshot은 일치했고 journal은 `COMPLETED34/34`다. 원생산자의138개 출력과 오류/receipt를 그대로 보존한다. 이 실행을 종료0으로 다시 이름 붙이지 않는다.

모델 계산을 반복하지 않고 [별도 감사 코드](../../analysis/audit_projected_pose_outputs.py)로 원출력을 읽었다. 고정 투영과 수정량, 실제 저장된 full_pose의 축 재추출/왕복, 원모델 strict/zero-mask후 벌점, 판정과 기존 표면QA 상태, 중복/neutral여부를 재검산했다. 누락 필드는 새 감사 출력에만 재구성했다. 새 감사는 `EXITED_ZERO`, 설정 포함795입력/17pin, 전후 snapshot일치, 출력3개 `RECORDED_FILES_MATCH`다. 추가 SDK/난수/영상은0이다.

생산자 코드에서 누락 필드는 수정했고, 집계 필드/분모를 포함한4개 검사를 통과했다. 수정 전 생산자 파일도 이전 manifest의 정확한 SHA256과 일치하도록 별도 private사본으로 보존했다. 이는 사후 확보한 hash일치 사본이며 사전 코드 보관이었다고 소급하지 않는다.
