# 조건부 손동작·표면 검사·진단 영상과 영상별 시간 — 2026-11-15

[연구 실행 순서](../research_goal_followups_2026-11-10.md#실행-순서와-기존-백로그-연결)를 유지했다. 촬영 원본/선별 입력을 기다리는 동안 가능한 3D 독립 개발이다. [기존 PCA8동작의 모델 제약 위반](2026-11-15_mano_model_prior_audit.md)에 이어 관절을 각각 균등 난수로 뽑지 않는 후보 생성·거부 기록·표면 검사·무가림 진단 영상 생산을 연결했다. 이번 사용자 요청으로 **영상별 실제 생성시간**도 기록했다.

## 생성 조건과 근거

BIO-09의 고정 저자 기본값과 앞서 대조한 해부학적 기준축을 사용했다. [출처/구간 JSON](../../references/manotorch_default_constraint_extraction.json)은 그대로다. 두 조건은 다음처럼 구분한다.

- `author_exact`: 양손 모두 저자 기본 구간 그대로 적용.
- `ideal_mirror_comparator`: 오른손은 동일, 왼손은 이상적 반사 기준축의 `(-x,-y,z)` 관계에 따라 구간과 각도 부호를 변환한 **프로젝트 비교 조건**. 저자 기본값이나 임상 한계로 표시하지 않는다. 원본 구간 문자열과 실제 변환 구간을 함께 보존한다.

두 동작 원형은 함께 굽히기와 순차 굽히기다. seed7/19 × 두 원형 × 양손 × 두 조건 = 16후보, 각25프레임이다. trajectory/geometry/appearance 난수 흐름을 분리하고 실제 뽑은 값·시간·관절 곡선·색·형상·원형/조건 부모를 보존했다. seed 재현은 잠근 실행환경 안에서 확인했다.

손가락별 공통 굽힘과 MCP/PIP/DIP 비율, 엄지의 별도 연동, quintic 진행/복귀와 지연을 명시했다. 굽힘40–60도·엄지 벌림22–34도 등의 추출 범위, 연동 계수, 형상 계수·2/3초 시간·색 변형은 **공학 대조 값**이다. Chen의 임상 연동 계수를 이 Euler 표현에 검증 없이 옮긴 것이 아니다. 저자 모델 제약을 적용한 것과 사람의 생체/편안함 검증을 구분한다.

모든 후보는 `QUARANTINED_DIAGNOSTIC`으로 남겼다. 매 시도의 STARTED/PROPOSED/DECIDED 또는 ERROR, 수정0개와 거부 이유를 기록했다. 원형2개/seed 수/후보 수를 독립 미사용 family나 보안 entropy로 세지 않는다. 공개 진단 recipe를 운영 문제의 비공개 공급으로 취급하지 않는다.

41프레임은 두 면을 양쪽으로 가로지르는 삼각형 교차 지표이며 공면/모호 닿음 분류는0이었다. 깊이·부피·접촉 힘의 측정은 아니다. 공통 꼭짓점 면 쌍 제외, 프레임 사이/인접 면/물체 검사의 부재와 열린 경계16개를 유지한다. 반사 비교의0건을 전체 관통 부재·생체 통과로 바꾸지 않는다. **모델 각도 조건 안에서도 표면 검사가 별도로 필요함**을 이번 후보에서 확인했다.

렌더러는 불투명 직교 투영의 픽셀 중심 barycentric z-buffer다. 깊이를 픽셀별로 비교하며 painter의 삼각형 순서로 가림을 결정하지 않는다. flat 색·양면·비사실적 조명이며 AA/질감/그림자/렌즈 보정은 없다. 비공개로 face ID/깊이/투영 좌표를 보관하고, 다시 읽은400프레임의 모든 픽셀 checksum과 PTS/FPS/크기/프레임 수를 확인했다. 오른손 기본·왼손 기본/반사 조건의 중간 프레임3장은 시각 확인했다. 전체 프레임을 사람이 주석한 결과는 아니다.

시간은 실제 초로 생성·저장했다. 각 Euler 성분의 속도/가속도 수치도 계산했지만 물체의3D 각속도 벡터나 사람의 안전 한계가 아니다. 기존 여섯 BMC 한계·물리 길이 단위·물체 역학·사람 이해/모방/편안함은 미확인이다. 최종 가림 영상0개이며 prod UI에도 넣지 않았다.

전자는 모델 계산과 사전 표면/특징 검사도 포함한다. CSV는 제안/합성, native 계산, BMC/모델 조건, 표면 검사, raster, 인코더 열기/쓰기/마무리, visibility 보관, decode 검사를 분리한다. 공통 모델 준비는 오른손약0.269초·왼손약0.169초로 별도 보존했으며 영상별 시간에 반복 합산하지 않는다. 패키지 import·기록기 snapshot/최종 receipt 봉인은 영상별 시간 밖이다.

영상의 마지막 동작 프레임 시각은2 또는3초이고, 마지막 프레임 한 장의 표시를 포함한 encoded 길이는25/FPS(약2.083 또는3.125초)다. 파일의 존재/mtime에서 생성시간을 역산하지 않았다. 로컬 고정 순서의 한 실행이며 OS/codec/BLAS cache와 배경 부하는 통제하지 않았다. 두 조건의 공정한 비용 우열이나 Cloud/운영 지연을 입증하지 않는다.

## 최초 실패와 실제 증거

최초 코드 `a179117` 실행은 중간 PNG의 파일명 API 저장 실패로 `PROCESS_ERROR`였다. 당시 journal은 ERROR, native26개가 계산됐고 첫 후보는13회 encoder write 뒤 중단됐다. 그 후보의 경과약4.739초와 부분 영상/파일16개를 보존했다. 완성 영상 시간은 null/CSV 빈칸이며0초로 세지 않는다.

같은 폴더의 작은 경로 대조에서 한글 포함 절대 파일명 API는 실패, 상대 ASCII 이름은 성공, `imencode`+pathlib 바이트 쓰기는 성공했다. 수정 코드 `110d546`은 이 저장 경로만 바꾸고 같은 생성/QC 조건을 새 폴더에서 실행했다. 실제 모델 범위나 판정 기준을 완화하지 않았다.

성공 실행 `EXITED_ZERO`, journal COMPLETED402/402, 전후 snapshot 일치, 입력105개·CPU 의존성17pin·출력203개 검산 통과. 실패 출력16개도 검산했다. 양 실행 합계 native 계산428개 중 완성 실행은402개이며 실패 자료를 성공 분모에 섞지 않는다. 연구 코드239개 검사 통과, 시간 exporter는 실제17행 export·성공/실패/빈 ready 시간·source 무결성을 검산했다.

주요 코드: `analysis/runtime_benchmark/mano_conditioned_generator.py`, `private_mesh_raster.py`, `analysis/export_conditioned_timings.py`. 새10개 검사는 seed/연동/끝점·구간/반사 분리·실패 timing·z-buffer 가림/깊이/순서/클리핑/퇴화를 확인한다. 모델·좌표·영상·visibility·개별 hash·상세 기록은 비공개이며 Git에는 코드와 식별 가능한 사람 자료가 없는 진단 집계만 올린다.

비공개 위치는 저장소 인접 `private_artifacts/mano_conditioned_20261115{,_v2}/`, `mano_conditioned_record_20261115{,_v2}/`, `mano_conditioned_config_20261115{,_v2}.json`, `opencv_unicode_preview_probe_20261115/`다. 실제 명령/시각/버전/입력·출력 연결은 로컬 receipt에서 재검사한다. 파일 무결성은 독립적인 출처·동의·생체 타당성 인증이 아니다.
