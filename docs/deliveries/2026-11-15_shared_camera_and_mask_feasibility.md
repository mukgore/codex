[실행 순서](../research_goal_followups_2026-11-10.md#실행-순서와-기존-백로그-연결)를 유지했다. 앞 단계 촬영/사람 입력은 대기다. [기존16개 조건부 후보](2026-11-15_mano_conditioned_videos.md)의 저장 좌표를 읽어 카메라와 가림 조건을 검증했다. 새 MANO 추론·난수 동작 생성·원본 배열 수정은 없다.

## 공통 카메라와 추가로 확인한 좌표 방향

첫 완료 실행은 한 카메라 축·크기·구도를 모든16후보에 적용했다. 두 시점은 같은 상하축을 유지하면서 수평축/깊이축을 함께 반전하는 proper camera다. 각 후보 첫 손목 위치의 평행이동만 제거하고 프레임마다 다시 맞추지 않는다. 전체 개발 source와 허용 가능한 원의 범위를 함께 담아 구도를 한 번 결정했다. 물리 카메라 보정이나 미사용 평가 자료의 구도 결정은 아니다.

이 기준에서 왼손이 거꾸로 보였다. 두 모델 중립 자세의 손목→중지MCP 방향 내적은 약-0.997이었다. 고정 카메라가 같아도 자산의 기본 좌표 방향이 다르면 모델 기준 자세가 정렬되지 않는다는 것을 실제 중간 영상과 좌표에서 확인했다.

두 번째 완료 실행은 손별 평균 중립 골격에서 정한 고정 proper 회전을 먼저 적용한다. 상하축은 손목→중지MCP, 가로축은 검지/소지MCP 방향의 직교 성분이다. 왼손의 가로 부호를 보정하고 법선을 외적으로 구성해 좌우 모양을 보존한다. 모든 프레임에 같은 회전을 쓰며 반사·크기 변경·프레임별 자세 fitting이 아니다. 원본3D는 그대로이고 렌더에만 첫 손목 평행이동과 이 회전을 적용한다.

| 실제 확인 | 공통 world 좌표 기준 | 손별 중립 정렬 후 공통 카메라 |
| --- | ---: | ---: |
| 기존16후보 × 두 시점 | 32영상 / 800프레임 | 32영상 / 800프레임 |
| 시점별 카메라 축/중심·공통 크기 동일 | 확인 | 확인 |
| 모든 프레임에서 중지MCP가 손목보다 화면 위인 렌더 | 16/32 | 32/32 |
| 고정 회전 후 원본 점-손목 거리의 최대 차이 | 적용 안 함 | 약5.55e-17 native 단위 |

새 모델 표본이나 독립 family가 늘어난 것이 아니다. 같은 후보의 두 모드·두 시점과 원래 오른손 중복 대조는 서로 관련된 자료다. 두 완료 실행의 중간 프레임을 각3장씩 시각 확인했고, 전체1600프레임은 lossless pixel checksum·PTS·프레임 수로 다시 읽어 검사했다. palm/back의 독립 주석이나 임상 기준축 검증은 아니다.

## 가림 선행 조건과 실제 거부

[MASK-01/03·GEN3D-04](../video_pool_occlusion_delivery_requirements_v0.4.md#9-mask-03--가림-적용과-출하-검사)를 읽고 기존 Stage6/7 조건을 유지했다. 중지PIP 및 두 중점의 내부 여유15%, 다른 손끝 최소2개의 외부 여유10%, 전 프레임 통과100%를 바꾸지 않았다. source별 일정한 w3의 교집합을 구하며 데이터셋의 일반 weight를 재보정한 것이 아니다.

추가한 모델 표면 proxy는 평균 중립 mesh의 정점을 가장 가까운20개 골격 segment에 배정한 뒤, 중지MCP–PIP/PIP–DIP에 속한 정점과 접한 **면 전체**다. 다른 손에 가려진 부분까지 고려하는 별도 amodal 투영을 생성했다. 이 정의는 기하학적 임시영역이며 독립적인 해부학 주석이 아니다. 두 픽셀 buffer는 래스터/기존 codec 검사 여유이고 인체 거리 단위가 아니다.

| 조건 | world 기준 | 중립 정렬 기준 |
| --- | ---: | ---: |
| 전 프레임의 기존 관절/단서 조건을 함께 만족할 일정 반경 | 0/32영상 | 0/32영상 |
| 한 프레임 자체에서도 반경 조건이 양립하지 않는 검사 건수 | 472/800 | 464/800 |
| 표면 proxy의 투영이 빈 프레임 | 0/800 | 0/800 |
| 실제 생성한 가림 후보 / H.264 | 0 / 0 | 0 / 0 |

프레임 검사 건수는 두 시점과 중복 대조를 포함하며 독립 표본 수가 아니다. 중립 정렬에서도 일정 반경의 최소 요구값이 최대 허용값보다 컸다. 즉, 중지를 충분히 가리려고 원을 키우면 공개 단서 손끝 둘을 유지할 수 없는 구간이 있었다. 단순한 출력 색상이나 codec 문제가 아니다.

기하 선행 조건이 없으므로 가림본/H.264를 만들지 않았다. 실제 mask ROI·distal patch·인코딩 후 proxy 픽셀의 값은 통과0건이 아니라 **미실행**이다. 해당 조건 분기 코드는 준비했지만 이번 자료로 검증됐다고 하지 않는다. 모델 표면 전체·공개 단서의 사람 인식·최종 byte 보안·그림자/반사·사람/공격 관문도 미완료다. 이전의3D 교차지표41프레임은 원본의 판정을 재사용한 것이며 이번1600프레임에서 새로 측정한 충돌 수가 아니다.

## 다음과 필요한 입력

완료는 공통 카메라 및 고정 중립 정렬, 전체 무가림 재렌더 검산, 일정 반경의 불가능성 진단과 시간 기록이다. 다음은 **생성 전에 공개 단서 손가락을 유지하는 조건을 넣은 동작 원형**이다. 기존 동시/순차 굽힘은 거부 대조로 보존하고 관절/단서 gate를 약화시키지 않는다. 가림이 가능한 경우에만 정확한 ROI·codec 분기로 넘어간다. 동작을 영상에서 추론할 수 있는지·복수 정답·사람 모방 가능성은 별도다.

임시 표면 정의 보강을 위해 BIO-09 저자 저장소의 `merged_vertex_assignment.txt`(778개·17label)와 loader도 확인해 private에 보존했다. source blob 바이트는 일치하지만 label→부위·우리 topology/좌우손 대응은 미확인이고 이번 렌더에는 쓰지 않았다. [학술 색인](../academic_reference_index.md)에 위치를 남겼다.

실제 촬영·독립 주석·선별/모방 응답·운영/공격 환경은 입력 대기다. 접수되면 앞 단계부터 우선 처리하며 [전체 큐](../remaining_work_master_2026-11-15.md)를 유지한다.

**사용자 요청으로 종료:** 이 단위의 기록·검산·브랜치 반영까지만 마무리하고 작업을 중단한다. 두 렌더 프로세스는 정상 종료했으며 새 생성/렌더를 시작하지 않는다. 위 다음 작업은 재개 후 큐다.
