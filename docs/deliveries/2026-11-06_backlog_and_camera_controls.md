## 같은 세션의 추가 검증

- 기존 G4 136개 좌표 조건을 로컬에서 재실행했다. 11개 조건 묶음의 점수/관문/입력검사/로컬 보호 동작/정지 필터 건수와 평균 점수가 이전 집계와 모두 같았다. 알려진 풀의 회귀이며 새로운 공격 성공률은 아니다.
- codex Python 74개, handcaptcha Python 109개와 JavaScript 29개가 통과했다. 별도 ffprobe 컨테이너 6조건도 기대대로 동작했다. Python 가상환경의 `pip check`가 통과했다.
- 기존 113프레임 원본을 Linux 감독기에서 처리해 113프레임 검출을 확인했다. 30초 한도에서 완료했고 0.15초 한도에서는 작업을 중단하고 저널을 복구했다. 배치 추출 검증이며 HaMeR 또는 운영 시간 비교가 아니다.
- 두 저장소의 가져온 Git refs에서 codex 248개, handcaptcha 283개 blob 및 ZIP 내부 7개 항목을 정해진 비밀값 패턴으로 재검사했다. 탐지 후보 0건이며 비공개 세부 경로·내용과 이미지 의미 검토는 집계에 포함하지 않았다.

## 현재 실행에 필요한 입력

- 카드 D의 실제 손 정지·모방·오답 비교는 동의·기록 정책을 확정하고 실제 카메라·참가자를 확보해야 한다. 로컬 영상 진단은 이 입력을 대체하지 않는다.
