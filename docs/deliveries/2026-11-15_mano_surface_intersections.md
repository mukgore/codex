# 생성 손 표면의 샘플별 삼각형 교차 검사

이미 비공개로 보관한 [랜덤 MANO8동작·192프레임](2026-11-15_mano_random_diagnostic.md)에 표면 검사를 추가했다. 새 모델 추론이나 사람/물체 실험은 아니다. 원본 격리 판정과 파일을 유지한 읽기 진단이다. [집계 결과](../../reports/mano_surface_intersections_20261115.json).

## 학술 근거와 구현 선택

[학술 색인 GEO-01](../academic_reference_index.md#기하표면-교차-검사--생체-근거와-분리)의 Eberly, *Method of Separating Axes*, §9/PDF18쪽의 두 삼각형 분리 축을 참고해 독립 구현했다. [원문](https://www.geometrictools.com/Documentation/MethodOfSeparatingAxes.pdf). 면 법선 두 개와 양쪽 변의 외적 축으로 투영 구간을 비교하고, 같은 평면의 삼각형에는 평면 안의 변 법선도 포함했다. GEO-02 Möller의 다른 알고리즘을 구현했다고 주장하지 않는다.

프로젝트의 공학적 선택은 다음과 같다. 삼각형 경계 상자로 먼저 후보를 줄인다. 공통 꼭짓점이 있는 면 쌍은 정상 연결부의 닿음을 피하려고 제외하고 수를 센다. 전체 mesh 대각선으로 크기를 정규화하고 상대 수치 허용값1e-7을 적용한다. 이 값은 생체 여유 거리/물리mm가 아니다. 퇴화 삼각형은 검사 불가로 처리하며 예산을 넘으면 오류로 끝낸다.

교차 지표를 공면 겹침·두 평면을 양쪽으로 가로지르는 지표·닿음/수치 모호성으로 나눈다. 이 분류는 관통 깊이·부피·접촉 힘의 측정이 아니다. 국소 면 법선/변 축 구현과 전체 3D 손 생물학적 타당성을 분리한다.

## 검사와 실행 기록

handcaptcha `670ec33`의 `mesh_intersections.py`, 연구 `1fd4285`의 `mano_surface_intersection_audit.py`. 교차/평행 분리·공면 겹침/비겹침·닿음·쌍 교환·이동/회전/크기·인접 면 제외·퇴화/잘못된 topology를 검사했다. 신규8개를 포함한 handcaptcha 전체150개 검사가 통과했다. 이 검사들이 exact predicate·모든 악조건·전체 논문 알고리즘 검증을 의미하지는 않는다.

실제 외부 기록은 기존 offline CPU 환경에서48입력·코드·26pin 환경을 snapshot한 뒤 `analysis.mano_surface_intersection_audit`의 source/source-record/worker/output 경로를 명시해 실행했다. `EXITED_ZERO`, 전후 snapshot 일치, 출력9개 재검사 통과. source 실행 기록도 전후 검산했다. 로컬 `private_artifacts/mano_surface_intersections_20261115/`, `mano_surface_intersection_record_20261115/`, `mano_surface_intersection_config_20261115.json`에 상세 삼각형ID/좌표 입력/기록을 보관하며 Git에는 코드·집계만 넣는다.
