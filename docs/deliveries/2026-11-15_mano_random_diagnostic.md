# 제한 랜덤 MANO 동작과 모든 시도/거부 기록

## 이번에 실제로 한 일

기존 사용자가 제공한 MANO와 설치된 CPU 환경으로 **양손×seed2개×시도2개, 총8개 동작·192프레임**을 새로 계산했다. 출력은 비공개 공학 진단이며 생체 승인 후보나 문제 공급 풀이 아니다. 모든 시도에서 뽑은 값·원래 관절/표면·전체 자세·실제 초·평가/거부 사유를 남겼다. [집계 결과](../../reports/mano_random_diagnostic_20261115.json).

관절을 하나씩 독립 균등 난수로 뽑는 대신 MANO PCA 성분1·2를 같은 왕복 곡선으로 결합했다. 성분1 진폭0.4–0.8, 성분2 진폭−0.08–0.08, 전체1.5–2.5초와 상승/유지 비율을 샘플링했다. 이 숫자는 기존 PC1 공학 재현 주변의 **진단 범위**다. 학술/관측으로 확인한 자연 동작·안전 범위가 아니다. quintic 곡선으로 상승·유지·복귀를 연결했지만 이것이 사람의 편안함이나 생체 속도 한계의 근거가 되지 않는다.

주seed·손·시도·version에서 SHA256으로 하위seed를 구분하고 NumPy PCG64의 trajectory 흐름을 사용했다. geometry/appearance 흐름은 식별자만 예약하고 실제로 사용하지 않았다고 기록했다. 형상은 모델 평균으로 고정했다. 입력 순서가 바뀌어도 같은 key는 같은 recipe를 만들며, 각 시도의 recipe를 모델 실행 전에 저장한다. 자동 재추첨·성공 수 채우기·규칙 완화·수정 후 원래 값 삭제는 하지 않는다.

## 실행 근거와 코드

생산 코드 `d178820`, hand 프로필 `b927813`. 연구 Python 전체198개, 기존 모델 runtime 안에서 sampler5개 검사가 통과했다. 실제 명령은 기존 CPU 환경에서 `analysis.runtime_benchmark.mano_random_diagnostic --seeds 7 19`를 입력/범위/worker/output 경로와 함께 실행했다. 외부 execution_record가 실제 전체 argv·시각·환경17pins·code/52입력 snapshot·종료와39개 산출물을 묶었다. 결과는 `EXITED_ZERO`, 전후 snapshot 일치, 전체39파일 재검사 통과다. hash는 변경 탐지 근거이며 독립 실험 인증/정답 보장은 아니다.

로컬 `deliverables-review/private_artifacts/`의 `mano_random_diagnostic_20261115/`, `mano_random_diagnostic_record_20261115/`, `mano_random_diagnostic_config_20261115.json`에 보관한다. 모델/라이선스 원문·배열·개별 입력 hash·상세 로그는 Git에 올리지 않는다. 새 설치·외부 전송·카메라 사용·GPU/Colab 실행은 없었다.
