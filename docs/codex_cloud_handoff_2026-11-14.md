이 문서는 새 작업에 전달할 지시문이다. 새 Cloud 작업을 생성하거나 현재 로컬 목표를 교체하지 않는다. [이전 조사/명령 초안](codex_cloud_migration_preparation_2026-11-14.md)의 미확인 사항과 승인 조건을 함께 읽는다.

```text
mukgore/codex와 mukgore/handcaptcha의 work/todo-consolidation-20261103을 사용한다.
docs/research_goal_followups_2026-11-10.md의 「실행 순서와 기존 백로그 연결」을 먼저 읽는다.
기존 backlog와 실험 카드는 세부 참고로 사용한다. 순서를 바꾸지 않는다.

인계 당시 연구 결과 commit은 codex 425f1dd, handcaptcha ebdfcb8이다.
이 인계 문서를 포함한 실제 최신 remote HEAD를 먼저 확인하고 작업 기준을 기록한다.
모델·개인 자료 없이 시작한다. 로컬 Windows PC와 연결된 remote 실행으로 대체하지 않는다.
새 환경 구축/연구 코드 변경은 사용자가 별도로 승인한 범위에서만 수행한다.

완료 단위: MANO 양손 flat-mean PC1, 각24프레임을 새 CPU 경로로 생성했다.
원래16관절/표면손끝5점/full pose/parent table을 비공개 저장했다.
이전 표면/21점/PCA 입력과 양손 모두 배열 값이 일치했다.
연구193개, hand pipeline138개와 마지막 bridge8개 검사 통과.
실패1회도 보존했다. 원본 prod hash는 조사 문서의 기준을 유지한다.
상세 실행 증거/모델/이전 비교 자료는 로컬에만 있으므로 Git에 있다고 가정하지 않는다.

우선 입력: 통제 촬영21행, 실제 사람 선별, 모방/정지 대응, 독립 주석은 대기였다.
실제 입력이 들어왔으면 원래 단계의 선행 조건부터 확인한다.
없으면 미완료를 명시하고 독립 개발을 계속한다. 사람 결과나 권리 기록을 만들지 않는다.
다음 3D 독립 개발은 관절 출처 계약을 유지한 제약 프로필과 제한 랜덤 생성/거부 기록이다.
생체 허용 수치/SI단위가 미확인이다. 진폭0.8을 생체 범위로 삼지 않는다.
무작위 샘플을 만들었다는 것과 생물학적으로 타당하다는 것을 구분한다.
UI는 항상 handcaptcha/hand_captcha_prod.html 기반이며 여섯 수정64조합을 유지한다.
채점은 현재2D 기준과 향후3D 후보를 구분한다. 같은 영상의 복수3D정답을 단일 오답 처리하지 않는다.

Cloud 초기는 모델 없는 연구 단위 검사·Node UI 검사부터 실행한다.
Linux/CPU/디스크/의존성/네트워크와 두 repo 접근을 실제 확인하고 미검증을 성공으로 보고하지 않는다.
Windows venv/wheel lock/절대 경로를 Linux에 그대로 재사용하지 않는다.
MANO와 개인 영상은 사용권·전송 승인·대상 저장처가 확인되기 전 업로드/다운로드/Publish하지 않는다.
새 모델 실행을 하려면 기존 비교 자료와 범위 증거도 필요하다. 누락을 임의 모델/수치로 채우지 않는다.
각 새 실험은 실제 명령·시각·코드/입력/환경 snapshot·종료·출력 hash를 남긴다.
과거 실행 정보는 소급하지 않는다. 실패를 보존하고 살아 있는 작업을 임의 재시작하지 않는다.
비공개 결과는 승인한 별도 저장처에 보존한다. 코드와 비식별 요약만 지정 GitHub 브랜치에 반영한다.
각 단계에서 완료/필요 입력/다음 선행 조건을 구분한다. 전체 연구 완료는 요구별 근거로 판단한다.
```
