## 명시적 누락/외부 의존성

- `pool_manifest.json`은 l1/l2/l3 및 custom01~08의 동영상/좌표 파일 11개를 참조하지만, manifest 자체 이외의 풀 원본 동영상·랜드마크는 제공 경로에서 발견되지 않았다. 워프된 custom01~08 영상 8개는 따로 존재한다.
- 참여자 원영상은 사용자 진술상 없다. 이것은 제시용/기준 영상이 모두 없다는 의미가 아니다.
- 노트북 3개에는 저장 출력 셀이 없으며, Colab·외부 파일 업로드·HaMeR 패키지/가중치/MANO 리소스를 요구한다. 로컬 GPU는 조사 불가 권한 오류; HaMeR 재학습/재추론 미실행.
- 원본 HTML에는 업로드 URL/폼 필드 및 특정 로컬 프로젝트 연동 코드가 있다. 이를 공개 가능한 환경설정·서버로 간주하거나 공개 저장소에 복사하지 않았다.
- `2차 테스트 분석/분석 보고서`는 재분석에 별도의 외부 저장소 절대 경로에서 baseline landmark를 찾아 사용했다고 서술한다. 그 자료는 제공된 트리에서 누락되었다. 별도 framewise 집계는 원본 좌표가 아니라 저장된 프레임 출력의 분석 산출물이다.

원본 경로/응답 파일을 공개 저장소에 복사하지 않는다. 신규 자료가 생기면 날짜만으로 버전을 정하지 말고 해시와 생성 코드로 계보를 추가한다.
