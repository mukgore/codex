# G3 해석 및 G4 기존 자료 평가 — 2026-10-24

## 공개 범위

이 문서는 기존 로컬 연구 자료를 사용한 오프라인 재실행의 비식별 집계 결과만 기록한다. 원자료, 개인별 행·좌표, 입력 해시, 로컬 절대경로는 포함하지 않는다. 새 참가자 데이터, 외부 서비스 제출, 배포는 수행하지 않았다.

## G3 해석

기존 인간 18세션은 점수 기준 17/18 통과했다. 기존 HaMeR 28조합은 점수 기준 28/28 통과했지만 조합 단위 전체 관문 통과는 10/28이었다. 관문과 점수 통과는 서로 다른 결과이며, 저장 실행은 fail-fast 전체 인증 흐름을 측정하지 않았다.

현재 결과는 인간이 자동 생성 궤적보다 보안상 우위라는 일반 주장을 지지하지 않는다. 반대로 선정된 자료와 구현에서 자동 생성 궤적이 점수 기준을 넘는 신호가 있다. HaMeR 조합은 8개 원동작을 공유하므로 독립 표본으로 해석하지 않는다. 인간 18세션과 challenge 및 실행 빌드가 연결됐다는 근거가 없어 코호트를 결합하지 않았다.

## G4 실행 1 — 랜드마크 재구성 조건 비교

8개 기존 동작 클립을 원본 원과 화면 고정 원 조건으로 각각 처리했다. 각 채널의 통과는 최종 점수 threshold 결과다.

| 지표 | 원본 원 (8개) | 고정 원 (8개) |
|---|---:|---:|
| 좌표 직접 주입 채널 점수 평균 | 0.77570 | 0.77951 |
| 좌표 직접 주입 점수 통과 | 8/8 | 8/8 |
| 합성 손 재검출 채널 점수 평균 | 0.36566 | 0.37186 |
| 합성 손 재검출 점수 통과 | 5/8 | 5/8 |
| 합성 손 검출률 평균 | 0.61510 | 0.61553 |
| 프레임 각도 오차 38° 이하 비율 | 0.90836 | 0.90506 |

안정 지표는 기존 저장 결과와 16행 모두 일치했고 최대 차이는 0이었다. 프레임 각도 통계는 세션 gate 성공률이 아니며, 점수 통과는 전체 인증 성공을 뜻하지 않는다. 고정 원 조건은 원의 크기·위치뿐 아니라 손 영상의 크기·좌표도 바꾸므로 원 크기 정보만의 인과효과를 분리하지 못한다. 이 비교는 고정 원이 공격을 낮춘다는 주장을 뒷받침하지 않는다.

## G4 실행 2 — 피부-bit closed-set 식별

8개 기존 영상에서 얻은 관측을 16개 저장 reference sequence에 대조했다. 8개 forward 관측에서 reverse 평가열을 파생했다.

- Hamming top-1: 14/16
- Majority top-1: 14/16
- 저장 궤적 재생 점수 threshold 통과: 16/16
- 재생 점수 평균: 0.973681

두 오인식 방향에서 선택된 잘못된 저장 궤적도 점수 0.854652로 threshold를 넘었다. 독립 JavaScript 재계산은 저장 점수와 8.89e-16 이내로 일치했고, bit 시퀀스와 예측은 기존 저장 실행과 일치했다.

평가 challenge와 reference library가 같은 8개 원동작을 공유하므로 이 결과는 closed-set 자료 내 확인이다. 독립 held-out 일반화, 실시간 gate, 실제 전체 인증은 평가하지 않았다.

## 결론과 남은 증거

- 확인됨: 두 기존 오프라인 경로가 로컬 CPU에서 재실행됐다. 독립 재집계 및 좌표 점수 재계산이 저장 결과와 허용 오차 내에서 일치했다.
- 조건부 재현: 입력 데이터와 후보 코드에 대한 재실행 결과다. 과거 세션의 실제 수집 빌드나 배포 환경을 확정하지 않는다.
- 자료 부족: 동일 challenge에서 인간과 공격자를 대응시킨 비교, source clip 단위 독립 held-out 평가, 실제 인증 흐름의 gate·score·전체 성공 지표가 없다.
- 해석 제한: 현재 결과는 선택된 자료에서의 취약 신호이며 CAPTCHA 일반 보안성이나 실사용 공격 성공률을 추정하지 않는다.

재현 스크립트와 입력 지문은 비공개 로컬 자료를 참조하므로 공개하지 않는다.
