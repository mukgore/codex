# 독립 검증 기록

## 수행 방법

별도 검증자는 분석 담당자의 `analyze_ab.py`, `replay_errors.csv`, `ab_stats_summary.json`을 계산 입력으로 사용하지 않고 원본 `captcha_ab_user_*.json` 10건을 Node 인라인 코드로 직접 읽었다. participantId 중복, A/B trial 존재 여부, 조건별 저장 점수·원시/추정 지표·duration을 재집계하고, 참가자 내 B−A와 가능한 2^10 부호 배정을 직접 열거했다. 좌표 replay 검증과 저장값 통계 집계는 별도 검증 범위임을 분리했다.

## 교차 확인 결과

- JSON 10건, unique participantId 10, AB 순서 4명, BA 순서 6명; 모든 기록에 A/B 각각 존재. 분석표 P01–P10 순은 입력 파일의 정렬 순서다.
- 조건별 최종 점수 평균/중앙값: A `.6450969147 / .6455127895`, B `.5094274623 / .5135483637`.
- 참가자별 B−A 점수(파일 정렬 순): −.1044570981, −.0393059281, −.1547500407, −.2137895597, −.1250810773, −.1588806968, −.0702324191, −.1050481548, −.2151926915, −.1699568578.
- 평균 B−A −.1356694524, SD .0578283633, exact two-sided sign-flip p=.001953125. 모두 B 점수가 낮다.
- 원시 B−A: angle +16.2101077778 (p=.001953125, 10/10 증가); dtw_angle +4.0064335200 (p=.015625, 8 증가/2 감소); accel +.0061317297 (p=.02734375, 8/2).
- 추정 B−A: sA −.3400963112 (p=.001953125); sDA −.0942312318 (p=.01171875); sAc −.0401013689 (p=.06640625).
- duration은 원본 ms를 1000으로 나눠 초로 변환했다. A 평균 29.74789초, B 31.38715초, 평균 B−A +1.63926초, SD 5.50997, exact p=.361328125.
- 모두 보고서 표와 부동소수점 정밀도 내 일치했다. **불일치나 수정 필요 오류 없음.**

## 해석 한계

표본이 10명이고 순서 군이 4명/6명이다. 정확 검정은 관측된 참가자 내 차이의 부호반전 분포를 사용한다. 임의 표본 추출을 보장하지 않으며, 참가자 모집·실행 순서·수집 빌드의 provenance 부족을 보완하지 않는다. 구성 지표 p값은 다중비교 보정 전이다. 시간값은 코드가 정의한 trial 시작/종료 이벤트 사이의 시간이므로 순수 반응시간으로 주장할 수 없다.
