## 표 7과 표 10이 연결되는 계산 경로

`occlusion_estimation_score.py`는 사람 시행의 raw metric을 **손을 구분한 action별로 먼저 평균**하고, 사람 검출률을 1로 두어 정규화한다. 이후 왼손 3동작·오른손 3동작을 같은 비중으로 평균한다. 위치 경향성에는 21개 landmark 쌍을 사용하고 이 경로의 정규화 함수는 clipping하지 않는다.

따라서 왼손 1세션은 총 비중 1/2, 오른손 각 세션은 1/6을 받는다. 네 참가자 동일 비중 1/4과 다르다. 단순히 지표 평균을 먼저 계산해서 선형성이 깨진 것이 아니다. **관측 비중, 지표 정의, 검출률 및 clipping 위치가 다르다.** 동일한 관측 비중과 점수 정의 안에서는 평균 가중합과 지표 평균의 가중합이 허용오차 안에서 일치한다.

## 집계·산식 및 검증

- 좌표는 XY만 사용하고 손목(0)을 원점으로 옮긴 뒤 손목–중지 MCP(9) 길이로 나눈다. 크기 분모 하한은 1e-6이다. Z·실제 timestamp는 지표에 쓰지 않는다.
- null frame은 버리고 보간하지 않는다. 각도 일반 비교는 유효 사용자 좌표를 baseline 길이로 선형 재표본화한 후 15개 관절의 도 단위 오차를 평균한다.
- DTW-관절은 관절별 절대차 비용의 unconstrained DTW 경로에서 오차를 평균한다. 역추적 동률은 대각/위/왼쪽 순이다. 최종 브라우저의 1.2배 sliding-window와 다른 정의다.
- 위치 경향성은 지정 landmark 쌍 거리 시계열의 Pearson r 평균이다. 표준편차 1e-8 미만 또는 비유한 상관은 0으로 둔다. 15쌍과 21쌍은 별도 정의다.
- 정규화 상수는 angle 39.1673, dtw_angle 32.6513, tendency 0.78이며 최종 가중치·상수로 교체하지 않았다. 전체 7지표도 재계산해 표 7 및 과거 재생을 감사했다.
- 유효 frame 3개 미만이면 지표가 결측이고 시행별 추정 점수는 0, trajectory는 10개 미만이면 결측이다. 이번 분석 대상에 해당 짧은 시행은 없다. 원 자료에 저장된 raw/estimated 점수는 없어 당시 점수 대비 오차는 계산 불가다. 과거 재생 CSV와의 비교는 이와 구분했다.
- 시행별 점수 → 동작/레벨별 → 세션별 → 전체 집계는 로컬 출력에 있다. 각 세션이 같은 9개 cell을 가져 세션 동일 비중과 시행 동일 비중 평균은 일치한다. 공개 요약은 개인값이 드러나는 손/action별 세부값을 제외했다.
- 프레임 수 가중 15쌍 경로의 레벨별 값은 0.550340071 / 0.567322293 / 0.522837417이고, 21쌍 경로는 0.592190087 / 0.605424250 / 0.546238059다. 샘플링 빈도 차이에 좌우되는 진단 집계이며 원 코드의 사람 평균을 대체하지 않는다.

수치 비교의 절대 허용오차는 **1e-8**, 소수 셋째 자리 표시 비교는 **0.0005**다. 표시 오차를 raw 수치 오차로 취급하지 않았고 목표값에 맞춰 허용오차를 늘리지 않았다.

새 코드의 36행 raw metric은 검토한 원 Python 함수만 격리해 실행한 결과와 최대 3.56e-15 이내에서 일치한다. 과거 독립 JavaScript 재생과는 세 CAPTCHA raw 항목의 최대 차이 3.56e-13, 최종 점수 차이 5.45e-15 이내다. 다만 점수에 사용하지 않는 DTW-거리에는 raw 최대 0.001511449 차이가 있어 전체 7지표가 모두 허용오차 내 일치한다는 판정은 하지 않았다.

그 DTW-거리 차이는 2행의 scalar DTW 경로에서 발생한다. JavaScript는 각 landmark의 x+y를 먼저 더하고, 원 Python은 좌표를 펼친 NumPy 평균을 사용한다. 합산 순서만 바꾸어 다시 계산하면 과거 CSV와 최대 2.67e-15 이내에서 일치했다. 작은 부동소수점 차이가 동률에 가까운 경로 선택을 바꾸는 현상이며 CAPTCHA 세 지표·본문 불일치의 원인은 아니다. 과거 4후보 지표 검증 기록의 범위는 이 새 감사 결과와 함께 읽어야 한다.

## 남은 공백과 원문 수정 제안

1. 본문 0.528/0.546/0.493을 출력한 시행별 결과표와 생성 스크립트/설정이 필요하다. 조사한 Python·notebook·기존 분석 산출물에서는 이 세 값을 해당 레벨 평균으로 생성하는 경로를 찾지 못했다. 0.522는 이 세 표시값의 평균으로만 맞는다.
2. `occlusion_estimation_score.py`가 참조하는 원 MediaPipe landmark JSON 6개와 반올림 전 관측 최대값이 필요하다. 알려진 Downloads 정리 연구 폴더, Documents의 CAPTCHA 연구 폴더·agents/snapshot 및 코드가 지정한 수신 연구자료 파일명 범위에서 대응 입력을 찾지 못했다. 모델을 새로 실행해 과거 원자료로 대신하지 않았다.
3. 표 7·표 10 후보 결과표는 발견했지만 실제 작품설명서에 사용된 실행 revision, 입력/필터 manifest 및 문서 연결 기록은 없다. 계산상 호환을 역사적 생성 경로 확정과 구분한다.

원문 수정안은 다음과 같다. 표 10의 0.557을 유지한다면 “표 7 레벨 3의 6개 손/action 동일 비중 지표 표시값에 초기 가중치를 적용한 재구성값”으로 정의하고, 참가자 동일 비중의 개인별 평균과 구분한다. 본문의 초기 평균 0.528/0.546/0.493/0.522는 생성 근거 미확정이라고 표시하고 원 실행 자료가 회수되기 전 0.557·0.548·0.525 중 하나로 임의 교체하지 않는다. 사람–HaMeR 격차도 같은 집계 정의·관측 단위를 정한 뒤 제시해야 한다.

## 재실행과 공개 범위

코드는 [reconcile_initial_scores.py](../../analysis/reproducibility/reconcile_initial_scores.py), 기계 판독 집계는 [summary JSON](../../reports/reproducibility/initial_score_reconciliation_summary.json)이다. 기존 requirements 환경에서 다음 명령을 사용한다. `$sessions`는 원 코드 목록 순서의 네 연구 JSON 경로 배열이며, `$candidates`는 별도 Downloads 후보 네 파일 배열이다. 경로값은 공개하지 않는다.

```powershell
.\.venv\Scripts\python.exe -X utf8 analysis/reproducibility/reconcile_initial_scores.py `
  --baseline $baseline --sessions $sessions --candidate-sessions $candidates `
  --previous-csv $previousCsv --comparison-workbook $comparisonWorkbook `
  --evidence-files $evidenceFiles `
  --private-dir data/initial_score_reconciliation/run `
  --summary reports/reproducibility/initial_score_reconciliation_summary.json
.\.venv\Scripts\python.exe -X utf8 -m unittest discover -s tests -v
```

실제 경로를 채운 재실행 명령 배열은 로컬 `data/initial_score_reconciliation/reexecution_command.json`에 있다. `data/run_initial_reconciliation.py`로 같은 입력 목록을 다시 실행할 수 있다. 이 두 파일과 입력/코드 해시, 검색 기록, 격리 실행·수치 비교, 가명 시행별 결과, 세션/action별 집계는 Git에서 제외된 `data/`에만 둔다. 원본은 읽기 전용으로 유지했고 분석 출력은 저장소의 별도 폴더에 썼다.

전체 `tests` 19개가 통과했고, 실제 자료의 9개 핵심 표 7 값·12행 workbook·선형 집계·동일 비중 일관성 검사도 통과했다. 나머지 표 7 네 표시값과 DTW-거리 비교 실패는 별도 진단으로 남아 있다. 공개 파일에는 원 JSON·좌표열·참가자 식별자·개인별 점수·입력 해시·사용자 절대경로를 포함하지 않는다.
