# TF-03 원형 없는 모델 공간 경로 파일럿 — 사전등록 v1

**실행 후 갱신:** [실제4경로·100프레임/102 SDK자세·시간/증거](deliveries/2026-11-16_template_free_paths.md)를 완료했다. 아래 ‘대기’는 실행 전에 고정한 상태다.

상태: 코드/실행 대기. [TF-02P 원출력 감사](deliveries/2026-11-16_projected_pose_audit.md)로18개 모델/샘플표면 후보를 확보한 뒤 등록한다. 사람 타당성·물리/연속충돌·생체시간 한계는 미확정이며 원래 실행 순서의 실제 입력이 오면 그 단계가 우선이다.

## 입력과 경로 선택

부모 SDK생산자는 최종집계 오류로 `PROCESS_ERROR`다. 검산된 원출력 감사는 별도 `EXITED_ZERO`이며, 그 감사의32행과 원생산자의 actual native파일을 함께 입력으로 묶는다. 이 두 상태를 합쳐 원생산자를 성공으로 승격하지 않는다. 원 receipt/모든원출력·별도 감사receipt/3출력을 검증하고 감사의 source-case/판정과 actual파일을 대조해야 한다. 누락/불일치는 거부한다.

손×seed4조건에서 모델/샘플표면 지표0이며 BMC feature 계산 가능한 자세를 attempt순으로 정렬해 처음3개를 시작/경유/목표로 선택한다. 사전 확인한 attempt는 right7=(0,1,4), right19=(2,4,5), left7=(1,4,5), left19=(0,1,3)이다. 각조건3개가 없거나 이 연결이 감사결과와 다르면 임의로 다른 endpoint를 찾지 않고 오류로 남긴다. 같은3자세를 되돌아오는 원형으로 바꾸지 않는다.

원형ID나 동시/순차 굽힘·선택손가락 목록을 선택하지 않는다. 이 경로는 이미 제안/수정된 서로 다른 관절 상태를 잇는 별도 C경로다. 같은 개발 계열/부모를 공유하므로 독립 문제4개로 세지 않는다.

## 고정 시간·보간과 예산

시간은0/1.5/3초에 세 waypoint를 두고25개등간격 샘플(dt=.125초)을 계획한다. 각 구간은 `q(u)=q0+(q1-q0)*(6u^5-15u^4+10u^3)`로 해부학적 intrinsic XYZ 성분을 잇는다. 이 easing은 경유상태 사이의 공학 보간이고 기존 굽힘-복귀 원형이 아니다. 모든경로가 중간에 정지하는 특성이 있으며 자연스럽다는 증거로 쓰지 않는다. 각구간은 등록 waypoint의 축별 구간 안에 있지만 실제 SDK 재추출/벌점은 매프레임 다시 검사한다.

경로4×25=100 SDK프레임+양손neutral2=102자세평가를 계획한다. 실제 호출은25자세배치4회+neutral단일2회=6회다. beta/root0, author_exact, 기존17pin/Torch1thread·600초, 새immutable출력/기록. 추가중간샘플·재시도·시간/endpoint/기준 조정은 이실행에 포함하지 않는다. 실패 시 원자료/기록을 남기고 새명세 없이는 성공 수를 채우지 않는다.

## 측정과 판정

각25프레임의 제안각/actual full_pose/16관절/표면tip/778정점·basis/시간을 저장한다. strict/저자 zero-mask후 모델 prior, 왕복오차≤1e-6, BMC정적feature 계산, 기존 비공통꼭짓점 샘플표면교차/퇴화를 측정한다. 제안 구간을 통과했다고 실제 SDK 벌점을0으로 대체하지 않는다.

실제 초 시간축의 각도 미분을 기록한다. intrinsic Euler 성분의 unwrapped index차분/dt 및 차분속도의 구간중앙시각 차분으로 rad/s·rad/s²를 산출하며, 이를 물리적 각속도벡터나 안전 상한으로 부르지 않는다. BMC 국소각의 기존 `angular_derivatives`도 실제 times_seconds로 별도 계산한다. 여섯 미확정 한계와 임상연동은 그대로 남기고 수치가 작다고 생체/편안함 통과로 판정하지 않는다.

경로별100/25프레임·모델/표면/feature 성공·실패 분모와 연속충돌 미검사를 구분한다. 전프레임 지표0인 경로는 `MODEL_CONSTRAINED_RESEARCH_ONLY`, `release_allowed=false`이며 최종영상·사람/공격·풀승인 후보가 아니다. sampled표면검사는 샘플 사이 충돌·인접면/부피/물체 역학을 보장하지 않는다. 연동은 수정된 모델 자세를 잇는 것으로, 원 PCA분포나 임상허용 결합영역을 보장하지 않는다.
