# TF-02P 수정 방법의 해석과 검토 — 2026-11-16

이 문서는 [고정 모델 제약 투영 사전등록](tf02_projected_pose_preregistration_2026-11-16.md)의 방법 검토다. 모델 계산·새 자세/영상 생성·수치 결과가 아니다. 공유 폴더의 별도 실행 흐름을 보존하면서 분리 작업트리에서 작성했다. TF-02P 실행/완료 여부는 해당 실제 receipt로 확인해야 하며 이 문서 자체를 실행 증거로 쓰지 않는다.

앞선 [TF-02 B32개 모두 거부](deliveries/2026-11-16_template_free_pose_pilot.md)는 고정6PC/scale.5 분포와 현재 저자 모델 prior에서의 관측이다. 모든 원형 없는 생성 방식이 불가능하다는 결론은 아니다. 제약을 포함하는 후속 방식은 기존 실패와 분리한 조건으로 평가한다.

## 투영이 보장하는 범위

TF-02P의 clamp는 **고정 해부학적 Euler 좌표에서 각 축의 모델용 구간으로 수정**하는 프로젝트 방법이다. 해당 좌표의 축별 상자 안으로 넣는 것이며, 3D 회전의 최단거리 수정·mesh 최소변형·생체 결합 허용영역으로의 최적 투영을 구현했다는 뜻은 아니다. 현재의 `assess`와 `compose_anatomical`/`extract_anatomical` 계약을 기준으로 해석한다.

MANO PCA의 계수는 원래 자세 제안의 출처로 보존한다. Euler 좌표를 수정한 최종 pose가 원래6PC 선형 부분공간이나 학습된 자세 분포에 남아 있다고 가정하면 안 된다. 현재 계획의 원계수·원/수정 pose·수정벡터 보존은 이 차이를 추적하는 데 필요하다. 수정된 결과를 ‘원래 분포에서 그대로 뽑힌 자세’라고 부르지 않는다.

## 실행 결과를 읽을 때 확인할 사항

1. **실제 반환값 검사:** 수정 입력이 아니라 SDK의 실제 full_pose를 재추출해 동일 저자 구간/zero-mask로 검사한다. root/beta 고정, neutral 기준축과 왕복 허용치도 확인한다. 표현/기하 계산 불가를 벌점0으로 대체하지 않는다.
2. **수정 규모:** 원래 거부된32개 중 몇 개를 몇 축에서 얼마나 바꿨는지 최대/L2 수정량과 함께 보고한다. 이는 고정 Euler 좌표에서의 수치이며 회전의 geodesic 거리나 사람의 부담으로 해석하지 않는다. 큰 수정으로 후보가 늘었으면 그 사실을 숨기지 않는다.
3. **중복과 퇴화:** 정확한 최종 vertex/joint 중복, neutral로의 붕괴, 서로 다른 제안의 동일 결과를 구분한다. 중복이 없다고 자연스러운 다양성이나 보안 entropy를 입증한 것은 아니다. 정적 자세에 ‘움직임 진폭’이라는 말을 쓴다면 neutral 대비 자세 차이라는 계산 의미를 명시하고 실제 시간 동작과 구분한다.
4. **빠진 결합 제약:** 축별 모델 구간은 손가락 간/관절 간 사람의 연동, BMC joint hull, 엄지 측정축과 개인차·부담의 대체가 아니다. 모델 prior/샘플 표면0과 생체 타당성은 별도다. 검산된 한계가 없는 관문은 미확정으로 유지한다.
5. **비교와 예산:** 같은32개 부모를 한 번 수정하는 사전계획과 실제 계산34회를 대조한다. A/B/U와 수정 arm은 자료를 공유하므로 독립 표본처럼 검정하지 않는다. 새 seed/추가 수정 반복·관문 완화로 성공 수를 채우지 않는다.
6. **다음 단계:** 실제 수정 후보의 모델/표면·중복·수정량을 확인한 뒤 TF-03의 경로/시간/충돌 명세를 별도 고정한다. 정적 자세가 유효해도 그 사이 경로를 승인할 수는 없다. 실제 촬영/선별/모방 입력이 생기면 원래 앞 단계가 우선이다.

학술 근거와 적용하지 못한 수치는 [TF-01 적용표](tf01_constraint_application_2026-11-16.md), [학술 색인](academic_reference_index.md), [고정 저자 모델 defaults](../references/manotorch_default_constraint_extraction.json)를 따른다. 이 검토는 기존 구현과 명세를 해석한 것이며 새 논문의 임상 허용값을 확보하거나 새로운 학술 알고리즘을 재현한 결과가 아니다.
