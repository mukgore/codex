# 학술 근거를 둔 손 동작과 제약 있는 랜덤 생성 — 2026-11-14

사용자 요청으로 생물학적 타당성과 랜덤 생성의 범위·순서를 명시한다. 기존 GEN3D-01/02에는 seed 재현과 인간 수행 가능한 접촉 계획 주변의 제한된 변형이 이미 포함돼 있었다. 아래는 그 구체화이며, 현재 코드가 이를 모두 구현했다는 뜻은 아니다.

## 현재 구현과 구분

**2026-11-14 코드 후속:** [BMC feature/프로필 구현과 실제 480프레임 진단](deliveries/2026-11-14_biomechanical_features_and_profile.md)을 수행했다. 계산 코드와 근거를 연결하는 형식은 있지만 내장 수치 범위는 모두 미확인이다. 기존 접촉 모형 288프레임의 local 기준은 퇴화해 계산 불가, 기본 template 192프레임은 계산 가능하나 미통과다. 아래 기존 fixture의 한계를 생체 검증 완료로 승격하지 않는다.

- 자체 fixture는 임의 공학 길이/IK/범위로 작성한 21점 뼈대다. 뼈 길이 유지·capsule/구 비관통·정해진 tip 접촉과 유지/해제를 검사한다. 사람의 관절 가동 범위·손가락 연동·자기 관통·속도/가속도·편안함을 학술 근거로 모두 검증하지 않았다.
- 현재 seed는 정해진 template의 굽힘 진폭 또는 구 반경 일부를 바꾼다. 다양한 자연스러운 동작을 제약 안에서 뽑는 완성된 랜덤 생성기가 아니다. seed 수·파일 수를 독립 동작 family 수로 세지 않는다.
- 기존 MANO 산출물 재검사는 새 자연 동작 생성·해부학 전체 보장·안정적 grasp의 입증이 아니다. 아래 연구들을 참고했다는 이유로 현재 자체 모형을 ‘생물학적으로 타당한 손만 생성’ 상태로 바꾸지 않는다.

## 확인한 1차 학술 근거와 적용 범위

2026-11-14에 저자/학회 공개 자료를 확인했다. 수치는 원문 근거·좌표계·적용 조건을 함께 추출한 뒤 프로필에 넣으며, 이번 문서에서는 새 관절 한계나 안전 속도를 임의 확정하지 않는다.

| 자료 | 직접 참고할 부분 | 이 프로젝트에서 별도 확인할 것 |
|---|---|---|
| [MANO, Romero et al., SIGGRAPH Asia 2017](https://mano.is.tue.mpg.de/index.html) | 사람 손 스캔에서 배운 형상/자세·pose-dependent 변형 표현 | 모델 prior를 통과했다고 모든 생성 동작의 해부학·역학·편안함이 보장된다고 해석하지 않음 |
| [Spurr et al., ECCV 2020: Biomechanical Constraints, 저자 공개 본문](https://jankautz.com/publications/WeaklySupervised3DHand_ECCV20.pdf) | 뼈 길이, 손바닥 구조, 굽힘/벌림의 상호 의존성을 나눠 다룸. 한계는 측정·문헌·3D 주석에서 정할 수 있음 | pose 추정의 soft constraint 연구다. 생성 시 hard rejection과 시간 연속 동작 검사를 별도 구현해야 하며, 논문 결과를 모든 사람의 수행 보장으로 쓰지 않음 |
| [GRAB, Taheri et al., ECCV 2020](https://grab.is.tuebingen.mpg.de/index.html) | 사람의 손·물체·몸 움직임과 접촉을 포함한 실제 시퀀스의 참고 | 선택 동작/기기/참가자에서의 편안함, 주석/추정 오차, 자산 사용 조건은 별도 |
| [D-Grasp, Christen et al., CVPR 2022](https://eth-ait.github.io/d-grasp/) | 주어진 물체 자세/잡기 참조에서 접근·잡기·이동을 물리 시뮬레이션과 함께 다루는 방법 | 현재 prescribed kinematics는 이 물리 검증의 대체가 아님. 코드/모델 도입·실행·권리 확인은 별도 |

이 표는 각 연구의 범위와 이번 설계에 대한 해석이다. 해당 논문의 알고리즘을 구현/재현했거나, 모델·자료의 사용 승인을 새로 받았다는 뜻은 아니다. 모델/가중치/원자료를 내려받거나 외부에 업로드하지 않았다.

## 생성 전에 고정할 제약 프로필

각 규칙에 `profile_version`, 출처의 페이지/표/식, 좌표계·관절 대응·단위, 적용 대상/조건, 수치 또는 허용 영역, 보간/경계 처리, 검증 사례를 연결한다. 근거가 없는 값은 공학 fixture 전용으로 표시한다.

1. **형태/자세:** 손 크기·뼈 비율·손바닥 구조, 좌우손 축, 엄지의 별도 움직임, 굽힘과 벌림 및 관절 간 연동을 기록한다. 각 관절을 독립 균등 랜덤으로 뽑지 않는다.
2. **시간:** 실제 초 단위의 궤적 연속성과 관절 속도/가속도를 검사한다. 정적 자세의 허용 범위를 시간상 자연스러움의 증거로 쓰지 않는다. 문헌/관측으로 근거를 갖추기 전 숫자를 ‘안전 한계’로 명명하지 않는다.
3. **표면/접촉:** 손 자체와 물체의 관통, 접촉 패치·유지·해제, 지지/중력/마찰 가정을 검사한다. G0에서 사용자의 실제 접촉 힘을 측정했다고 주장하지 않는다.
4. **화면/문제:** 최종 가림·원 밖 단서·복수 해석을 검사한다. 3D 제약을 통과해도 최종 영상이 같으면 단일 숨은 깊이 답을 요구하지 않는다.
5. **사람:** 실제 이해·모방·부담/중단을 관측해 후보를 수정/제외한다. 컴퓨터 규칙 통과와 사람의 편안한 수행은 별도 상태다.

‘생물학적으로 타당한 후보’의 목표는 이 근거/검사 범위 안에서만 주장한다. 전체 검사가 미구현·미확인인 경우 일반 후보로 승격하지 않고 `RESEARCH_FIXTURE_ONLY`/`release_allowed=false`를 유지한다.

## 제약 있는 랜덤 생성 절차 — 계획, 아직 전체 미구현

1. 근거 있는 동작/접촉 계획과 물체 family를 먼저 선택한다. 해부학적/시간적 제약 프로필이 없는 계획은 검증된 생성 경로에서 거부한다.
2. 그 조건 안에서 손 형태, 초기/목표 자세, 물체 크기/방향, 이동 경로와 시간 변형을 샘플링한다. 학습 prior를 쓰면 그 모델/버전·분포와 허용 범위를 함께 잠근다.
3. 형상·관절 연동·시간·자기/물체 충돌·접촉 검사를 거쳐 거부/수정한다. 수정했다면 처음 뽑은 값과 수정 후 값·이유를 둘 다 보존한다. 물리 검사가 없는 모드를 물리 통과로 표시하지 않는다.
4. 최종 렌더/가림/codec·모호성 관문을 통과한 후보만 비공개 연구 풀에 추가한다. 시도 수·시간 예산을 두고 부족하면 실패/부분 결과로 끝내며 규칙을 완화해 성공 수를 채우지 않는다.
5. 주 seed와 RNG/생성기/프로필 버전, geometry·trajectory·appearance의 하위 난수 흐름, 실제 샘플 값, 모든 시도/거부 사유, parent/변형/노출 이력을 남긴다. 같은 seed의 재현성과 서로 다른 family의 다양성을 따로 검사한다.
6. scene/object/contact/trajectory/camera/renderer family로 자료를 나눈다. 새 seed만 바꿔 미사용 평가 자료로 주장하지 않는다. 실제 사람/공격에는 같은 정보·시간·재시도 예산을 적용한다.

형태/동작을 고정한 채 카메라·색·조명만 바꾸는 변형도 별도 기록한다. 이런 변형이나 거부 후 남은 파라미터 조합 수를 보안 entropy 또는 고유 동작 수로 세지 않는다.

## 실행 순서

장면 계보와 feature/profile 진단 단위를 마쳤다. 다음은 **실제 손 골격·엄지/좌우손·물리 길이 단위의 대응과 허용 수치의 근거**다. 기존 MANO/실측 참고 자료도 출처/단위부터 확인하며 임의 수치로 손바닥 퇴화를 덮지 않는다. 그 뒤 제한된 랜덤 샘플러·모든 시도 기록·거부 이유 검증으로 이어진다. 해부학 프로필/물리/사람 검증이 없는 현재 fixture의 무작위 범위만 넓혀 연구용 문제 공급이 완성됐다고 하지 않는다.

원래 1–4단계의 촬영·사람 응답·독립 평가 자료가 확보되면 그 우선순위가 먼저다. 모델 자산·허용 runtime·사람의 실제 편안함/정답 집합은 필요한 입력으로 남긴다. 모든 실제 생성/분석 실행은 [실험 실행 증거 기준](experiment_evidence_protocol_2026-11-14.md)을 따른다.
