# 동작 원형 없이 만드는 제약 생성 경로 — 2026-11-16

사용자 요청: 기존의 정해진 동작을 조금씩 변형하는 생성은 유지하고, **미리 정한 동작 원형을 고르지 않고 자세와 움직임을 생성하는 별도 경로**를 학술 근거에 따라 시도한다. 이 문서는 구현·실험 전에 고정할 연구 방향이다. 이번 정리에서는 새 생성 코드·모델 다운로드·학습·렌더·실험을 시작하지 않았다.

‘원형 없음’은 동시/순차 굽힘, 중지만 굽히기 등의 작성된 동작 목록과 고정 굽힘-복귀 시간곡선을 먼저 선택하지 않는다는 뜻이다. 손 모델·학습 prior·관절 제약까지 없앤다는 뜻은 아니다. 기존 원형의 이름만 없애거나 진폭/시간/seed만 바꾼 결과를 이 경로의 성공으로 세지 않는다.

## 유지할 경로와 새 경로

| 경로 | 생성 방식 | 상태와 비교 목적 |
|---|---|---|
| A: 원형 조건부 | 기존 동시/순차·선택 손가락 원형의 진폭·시간·형상 등을 변형 | 기존 코드/산출물 보존. 재현과 비교 기준으로 유지하며 사람 타당성 승인으로 승격하지 않는다. |
| B: 원형 없는 자세 | 손의 해부학적 좌표에서 연동된 허용 영역 또는 학습된 자세 분포를 이용해 상태 제안 → 제약 검사/수정 | 신규 계획. 독립 관절별 균등 랜덤을 최종 생성기로 쓰지 않는다. 기존 PCA 진단도 비교 기준이며 충분한 제약 생성기로 간주하지 않는다. |
| C: 원형 없는 움직임 | B의 유효 후보 사이에 경유 상태·경로를 제안/탐색하고 시간·충돌 제약으로 검사 | 신규 계획. 고정 굽힘-복귀 파형 대신 경로를 생성한다. 보간이 부드럽다는 것만으로 자연스러운 움직임을 입증하지 않는다. |
| D: 물체 조건부 학습 생성 | 물체에 맞는 잡기 상태를 학습 분포에서 제안하는 방법 검토 | 후속 후보. 손만 있는 현재 진단과 다른 과제이며 가중치/자료 권리·접촉/물리 검증이 먼저다. |

기존 [학술 색인 BIO-01–09](academic_reference_index.md)와 [BibTeX](../references/hand_research_core.bib)를 계속 사용한다. 아래는 논문의 범위와 **우리 연구 제안**을 구분한 연결이다. 확인일 2026-11-16에 MANO·GRAB 공식 안내와 BMC 저자 공개 본문을 다시 열었다. 모든 논문을 새로 정독하거나 알고리즘을 재현한 것은 아니다.

## 재개 후 실행 단위와 선행 조건

원래 [실행 순서](research_goal_followups_2026-11-10.md)의 1→2→3A→3B→4→5→6과 [전체 통합 큐](remaining_work_master_2026-11-15.md)를 유지한다. 실제 촬영/선별 자료가 들어오면 그 앞 단계가 우선이다. 이 경로는 입력 대기 중 가능한 3D 공급 연구의 추가 분기이며 다른 백로그를 대체하지 않는다.

1. **TF-01: 적용 가능한 제약 명세.** BIO별 원문 절/식/표, 관절/축/단위/중립/좌우손·연동·대상/과제, 수치 확정 여부를 표로 고정한다. BMC 미확정 값과 시간/연속 충돌 관문을 명시한다. 현재 모델 prior만 쓸 수 있다면 결과는 `MODEL_CONSTRAINED_RESEARCH_ONLY`로 격리한다. 사람 타당성 승인은 보류한다.
2. **TF-02: 자세 제안의 작은 시범.** 원형 ID 없이 연동된 관절 상태 또는 자세 prior에서 제안하고 모델 prior·형상/뼈·표면 검사로 거부/수정한다. 먼저 표현과 역변환을 확인하고, 실제 실행 전 seed·시도/시간 예산·검사 범위·실패 조건을 등록한다. 기존 조건부 A 및 무제약/PCA 제안을 같은 예산의 대조로 둔다. 제한값이 없으면 한계 미확인 상태를 그대로 내고 임상 통과를 주장하지 않는다.
3. **TF-03: 움직임의 작은 시범.** TF-02의 후보에서 시작/목표/경유 상태와 경로를 생성한다. 전 프레임의 연동 제약, 실제 초 단위 속도/가속도, 샘플 사이 보간/충돌 위험을 검사한다. 근거가 없는 시간 한계는 공학 가정으로 표시한다. 유효한 정적 자세 두 개만으로 그 사이 움직임을 승인하지 않는다. 원형 동작을 먼저 선택하지 않았는지 제안 과정도 기록한다.
4. **TF-04: 기존 영상/채점 경로와 같은 조건에서 대조.** 기존 author-region union, 고정 카메라/가림/codec 관문을 유지하고 계보·최종 파일 중복·노출을 다시 검사한다. A/B/C를 같은 영상 길이/시점/계산 예산에서 비교한다. 형상·동작·시점·렌더/최종 바이트 중복을 따로 세고 다른 seed를 독립 family로 세지 않는다. 기존 prod 채점 수치 진단은 실제 카메라/hold/인증 결과와 분리한다.
5. **TF-05: 실제 사람/독립 평가와 선택.** 해석·모방·부담·복수 답을 사람 자료로 확인한 뒤 채택 여부를 정한다. 사람/모델의 정보·시간 예산과 독립 split을 고정한다. D는 필요와 권리/자산이 확인된 뒤 별도 과제로 평가한다. 새 경로가 A보다 좋다고 미리 정하지 않는다.

모든 시도에 제안값/수정값·거부 이유·난수 계열·코드와 환경·전체 입력·시간·출력 hash를 남긴다. 특히 TF-02/03은 원형 ID/고정 원형 궤적을 입력으로 받지 않는 것을 실행 명세에서 확인한다. 실패/0개 채택도 결과이며 성공 수를 채우려고 분포나 관문을 몰래 바꾸지 않는다. 세션 인계와 다음 작업의 구체적인 시작점은 [인계 문서](SESSION_HANDOFF_2026-11-16.md)에 둔다.
