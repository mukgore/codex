완료 `shared_simplex_tf03_20261117_v1`/`shared_simplex_tf03_record_20261117_v1`의100프레임·932,000공유쌍 검사 중 수치 판정 불가8건(4프레임)만 후속 검사한다. 원float 출력8개와 판정은 변경하지 않는다. 원source는 동일 TF-03 완료28출력과 기록이다. 932,000건을 다시 계산하거나 SDK/영상/사람 실험을 추가하지 않는다.

저장 좌표를 binary64로 읽고 `Fraction.from_float`로 각 값을 정확 유리수로 변환한다. 공통 점을 원점으로 둔 두 평면의 비정규화 법선·외적·절단 구간을 유리수로 계산한다. 공면은 유리수 반평면 절단, 비공면의 공유 변은 공통 변 교선의 항등식, 비공면의 공유 점은 두 절단구간 교집합을 사용한다. 결과 꼭짓점에서 공유 점/선분까지의 거리 제곱과 전체 mesh 대각선 제곱×(고정1e-7)²을 유리수로 비교한다. 정확 연결부 밖 여부와 기존 수치 해상도 초과를 따로 보고한다. float 정규화 좌표를 재변환하지 않는다. 이는 저장된 binary64 기하의 정확 계산이며 실제 신체/측정 오차나 모든 쌍의 exact predicate 인증이 아니다.
